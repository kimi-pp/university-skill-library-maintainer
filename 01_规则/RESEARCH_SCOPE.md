# 调研范围规则

最后更新：2026-08-08

## 全局规则

每轮实际调研范围由用户当次任务限定。任务开始时记录平台、生态、功能分类、角色、来源、验证深度、交付形式和完成判据。总体分类体系只提供组织框架，不自动触发全量调查。

## 首轮任务范围

- 平台：仅 GitHub
- 分类 01：学术写作、引用与出版
- 分类 02：文档、表格、演示文稿与办公自动化
- 分类 03：文献检索与学术研究
- 候选形态：结构化 skill、社区 skill、可移植 agent 工作流、可合理改造为 skill 的开源命令包或任务模板
- 关联资源：MCP、脚本、模板、数据文件和说明资源只作为主体 skill 的关联资源记录
- 验证深度：默认一级说明验证；重点候选增加二级包内容验证
- 运行规则：本轮不安装、不运行；用户另行明确指定时除外
- 交付：三个独立 Excel、三个独立 Word、三个分类 Markdown 知识库与验证记录

## 本轮范围外

- GitHub 以外的 skill 市场、网站、论坛或代码平台
- 与三个指定分类无直接关系的候选
- 单独的软件产品、数据库或 MCP 服务，除非作为 skill 关联资源
- 运行性能、安全攻击面和真实账号集成测试

## 第二轮任务范围：分类 04 与 05

- 平台：仅 GitHub
- 分类 04：图书馆与信息素养
- 分类 05：编程、数学、数据分析和可视化
- 主要角色：高校学生、教师、科研人员、图书馆员、教学支持、行政与信息化人员
- 候选形态：结构化 skill、社区 agent skill、可移植工作流、可合理封装为 skill 的公开任务模板
- 验证深度：默认一级说明核验；高优先级或结构复杂候选增加二级包内容验证
- 运行规则：不安装、不运行；用户对具体候选另行明确指令时除外
- 交付：两个独立 Excel、两个独立 Word、两个分类 Markdown 知识库、来源与验证记录

### 分类 04 纳入边界

- 纳入：图书馆咨询与教学、检索策略与数据库导航、来源可信度评价、事实核查与媒体素养、书目/馆藏元数据、数字馆藏与档案、开放获取与版权素养、研究数据管理和学术传播支持。
- 与分类 03 重叠时，面向“找论文和做研究”的技能归入 03；面向“教会用户检索、评价、组织和合规使用信息”或图书馆业务的技能归入 04。
- 排除：只有普通搜索、没有教学/评价/馆藏工作流的泛用搜索工具；不能形成 skill 工作流的单独图书馆软件。

### 分类 05 纳入边界

- 纳入：代码编写、理解、调试、测试、审查与仓库导航；数学推理与证明；数据导入、清理、探索、统计、建模、机器学习、科学计算、数据库/SQL、图表、地图、网络与交互可视化。
- 与分类 02 重叠时，主要目标是办公文件操作的技能归入 02；主要目标是可复现分析、计算或可视表达的技能归入 05。
- 排除：纯部署/运维、攻击性安全、仅支持单一商业平台且无可移植方法的工作流，以及没有说明或任务边界的代码片段集合。

## 饱和判据

在指定分类内完成结构化 skill、社区集合和可适配工作流三条发现路径；针对遗漏子领域完成补充检索；连续两轮补充检索未发现有实质区别的新候选后停止发现。

## 学科打样范围：0809 计算机类

- 学科：仅本科专业目录中的 `0809 计算机类`，覆盖其 14 个专业，不自动扩展到其他一级学科。
- 平台：不再限于 GitHub；允许 GitHub、GitLab、Codeberg、Gitee、SourceHut、Hugging Face 公开仓库，以及能回溯到版本化公开源仓库的开放 skill registry/集合。
- registry、搜索引擎和精选列表仅用于发现；正式证据必须落到公开可读、可版本化的源码或 skill 包。
- 主要角色：计算机类学生、教学人员、科研人员、实验室与课程技术支持、信息化和软件开发员工。
- 能力范围：计算基础与编程、软件工程与测试、网络与防御性安全、物联网与嵌入式、AI 与数据、空间信息、数字媒体、保密与数据治理。
- 验证深度：所有正式候选至少完成说明验证、包结构验证和静态安全准入；只读说明不足以单独进入正式报告。
- 运行规则：不安装、不运行、不调用候选外部服务；用户对具体候选另行明确授权时除外。
- 交付：独立 Excel、独立 Word、Markdown 学科知识库、专业—skill 映射和静态安全审查记录。
- 正式准入：只允许 `SA` 或 `SB`；`SC`、`SX`、关键内容不可读或无法回溯上游的候选只进入内部排除归档。

## 功能分类 06 全网公开技能调研

- 分类：仅 `06 课程设计、教学材料与教学评估`，按 06-01 至 06-12 十二个小分类组织。
- 发现范围：全网公开来源，包括 GitHub、GitLab、Gitee、Codeberg、SourceHut、Hugging Face、公开技能目录、高校和教学技术组织的公开页面，以及其他可追溯开放来源。
- 证据要求：搜索结果、榜单和市场卡片只用于发现；正式证据必须回到固定版本公开源文件或完整可读技能包。
- 候选形态：结构化 skill、社区 agent skill、可移植工作流，以及能够合理改造成 skill 的高质量开源教学命令包或模板组合。
- 主要角色：高校教师、助教、教学管理人员、学生和课程支持人员。
- 运行规则：本轮不安装、不运行、不登录候选服务，也不上传真实作业、成绩、个人信息或未公开论文；用户另行明确指定候选和范围时除外。
- 安全规则：所有正式候选必须完成固定版本静态检查与教育场景安全审查；只允许 SA、SB 和 SB-A，SB-A 只收录适配后方案。
- 正式排除：SC、SX、许可证不清、来源或版本无法确认、功能证据不足、实质重复和偏离十二类边界的候选只留内部记录。
- 停止条件：每个小分类覆盖代码平台、技能目录或开放市场、教育机构项目、其他公开来源四类路径；连续两轮补充检索没有发现可正式收录且功能实质新增的候选后停止。
- 交付：大分类总览和十二个小分类分别生成 Excel 与 Word，共 26 个正式文件；另建 Markdown 知识库、来源快照索引、安全审查和内部过程记录。
