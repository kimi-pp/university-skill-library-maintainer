# 项目章程

最后更新：2026-08-06

## 宗旨

建立面向高校学生与员工的 agent skill 调研知识库，为技能选型、适配、安装和后续内部开发提供可追溯依据。

## 权限与范围

- 用户每次发布任务时限定当轮调研范围。
- 项目规则负责定义统一字段、验证方式、记录方法和交付格式。
- 未被当轮任务纳入的生态、分类或来源不自动扩展。
- 用户的新指令优先于已有规则；冲突内容写入决策日志。

## 工作原则

- 广覆盖、后分层，不因兼容性或风险提示过早删除有价值候选。
- 事实、验证观察和项目判断分开记录。
- 默认只读验证，不安装、不执行候选。
- 排除项内部留痕，但不进入最终 Excel 或 Word。
- 知识库按分类和候选拆分，使用索引按需读取。
- 原始资料保持不变，派生数据另存并记录来源。

## 完成定义

每轮任务只有在指定范围覆盖、候选验证、数据完整性、独立交付和文件可用性检查全部通过后才可声明完成。
