# 数据字典

最后更新：2026-08-07

## 正式候选字段

| 字段 | 必填 | 含义与填写规则 |
|---|---:|---|
| 内部标识 | 是 | `GH-分类号-四位序号`；同一分类内唯一 |
| Skill名称 | 是 | 仓库或技能包使用的原始名称 |
| 规范名称 | 是 | 便于中文检索的统一名称 |
| 功能一级分类 | 是 | 仅使用 01、02、03 对应分类名称 |
| 功能二级标签 | 是 | 一个或多个具体能力标签，以中文顿号分隔 |
| 关联分类 | 否 | 同一候选适用的其他一级分类 |
| 原生生态 | 是 | 使用 `TAXONOMY.md` 允许值 |
| 来源形态 | 是 | 可多值；使用 `TAXONOMY.md` 允许值 |
| GitHub仓库地址 | 是 | 仓库根地址 |
| GitHub技能路径 | 是 | 具体技能目录、`SKILL.md` 或最接近功能说明的仓库路径 |
| 发布者 | 是 | GitHub owner 或明确的维护组织 |
| 简要功能 | 是 | 一至两句中文描述，不使用营销措辞 |
| 详细功能摘要 | 是 | 说明主要步骤、产出和边界 |
| 适用用户角色 | 是 | 学生、教学人员、科研人员或行政与专业支持人员，可多值 |
| 典型高校场景 | 是 | 说明具体任务，不只写抽象领域 |
| Codex兼容等级 | 是 | A、B、C、D；X 不进入正式数据 |
| 适配建议 | 是 | 直接使用、轻量调整、深度重写或仅参考的方法说明 |
| 关联资源类型 | 否 | MCP、脚本、模板、数据文件、说明资源等 |
| 关联资源地址 | 否 | GitHub 内对应文件或目录地址 |
| 外部依赖 | 是 | 无则填写“未见明确外部依赖” |
| 许可证 | 是 | 仓库声明；未找到时写“未明确” |
| 维护状态 | 是 | 活跃、低频维护、停更迹象或无法判断，并保留判断依据 |
| 风险提示 | 是 | 客观记录权限、外部服务、数据上传或维护风险；无明显风险也需说明 |
| 验证级别 | 是 | 一级说明验证、二级包内容验证或用户指令运行验证 |
| 验证状态 | 是 | 使用 `VALIDATION_PROTOCOL.md` 允许值 |
| 验证证据位置 | 是 | 本地验证记录路径及 GitHub 证据地址 |
| 最近核验日期 | 是 | `YYYY-MM-DD` |
| 推荐优先级 | 是 | 高、中、低 |
| 重复或关联条目 | 否 | 记录上游、镜像、分叉或同技能跨分类标识 |
| 备注 | 否 | 只放无法归入其他字段的补充信息 |

## 学科打样扩展字段

| 字段 | 必填 | 含义与填写规则 |
|---|---:|---|
| 学科打样标识 | 是 | 使用 `DISC-0809-四位序号`，与既有 `GH-*` 功能分类 ID 并存 |
| 一级学科 | 是 | 固定为 `0809 计算机类` |
| 适用专业 | 是 | 使用源目录中的 14 个专业名称，可多值 |
| 主能力群 | 是 | 计算基础、软件工程、网络安全、物联网、AI与数据、空间信息、数字媒体、保密治理之一 |
| 覆盖类型 | 是 | 专业核心、跨专业通用或员工支持 |
| 来源平台 | 是 | GitHub、GitLab、Codeberg、Gitee、SourceHut、Hugging Face 或开放 registry |
| 发现地址 | 是 | 搜索、registry 或精选集合中的发现页面 |
| Canonical source | 是 | 版本化公开源码、skill 包或最接近入口文件的地址 |
| 审查版本 | 是 | 提交哈希、tag、release 或访问时默认分支状态 |
| 静态安全等级 | 是 | SA、SB、SB-A、SC 或 SX；SC/SX 不进入正式数据，SB-A 必须标注“仅适配后使用” |
| 准入形态 | 是 | 原包可用、限制使用或仅适配后使用 |
| 适配保留范围 | SB-A 必填 | 明确保留的说明、模板、参考资料或已审脚本 |
| 适配剥离范围 | SB-A 必填 | 明确删除或禁用的安装段、脚本、联网、凭据、发布、推送和高权限步骤 |
| 可执行行为 | 是 | 脚本类型、进程、动态执行和安装钩子；无则写“未见可执行载荷” |
| 网络与数据行为 | 是 | 域名、上传、遥测、凭据、秘密和外部写入 |
| 安全限制条件 | 是 | 固定版本、最小权限、人工确认、禁用外部写入等；无则写“无额外限制” |
| 安全证据位置 | 是 | 本地审查记录及公开源文件地址 |

## 内部排除字段

排除记录只保存在内部 Markdown 中，至少包含原始名称、GitHub 地址、判定日期、排除原因和与正式候选的重复关系。排除记录不得写入最终 Excel 或 Word。
