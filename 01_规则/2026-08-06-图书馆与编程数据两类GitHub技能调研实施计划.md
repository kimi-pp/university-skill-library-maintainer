# 图书馆与编程数据两类 GitHub 技能调研 Implementation Plan

> **For agentic workers:** 本计划在当前任务中顺序执行；遵守项目规则，不派生子任务，不进行候选安装或运行。

**Goal:** 在 GitHub 范围内系统发现、去重、核验并记录“图书馆与信息素养”和“编程、数学、数据分析和可视化”两类可用于高校学生及员工辅助系统的 skills，并分别形成 Excel、DOCX 和 Markdown 知识库。

**Architecture:** 以 `catalog_data.py` 为规范数据源，经过 GitHub 检索、上游去重、说明/包内容核验后生成分类 JSON、知识库、验证记录和独立报告。分类 04 与 05 不与现有分类合并；跨分类能力用关联字段说明。

**Tech Stack:** GitHub CLI/API、Python 规范数据与 DOCX 生成、`@oai/artifact-tool` XLSX 生成、Markdown 索引、结构与视觉验证脚本。

## Global Constraints

- 来源平台：仅 GitHub。
- 功能分类：04 图书馆与信息素养；05 编程、数学、数据分析和可视化。
- 入选形态：结构化 `SKILL.md`、社区 agent skill、可移植工作流，以及能够合理封装为 skill 的公开任务模板。
- 生态与来源形态必须独立标注。
- 落选、重复、失效和仅关键词命中的候选不得进入 Excel 或 DOCX。
- 默认只做一级说明核验；重点候选做二级包内容验证。
- 不安装、不运行候选；只有用户另行明确指定时才能执行。
- 每个分类分别生成一个 XLSX、一个 DOCX 和一个 Markdown 分类入口。
- 交付数据日期统一为 `2026-08-06`；Stars、推送日期和许可证按该日读取结果记录。
