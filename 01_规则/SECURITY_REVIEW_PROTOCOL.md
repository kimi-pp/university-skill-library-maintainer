# Skill 静态安全审查协议

最后更新：2026-08-07

## 目标与结论边界

本协议用于在不安装、不运行候选的条件下，识别明显恶意行为、高风险默认行为、供应链风险和权限边界。通过审查只表示“在已读取的版本和公开内容中未发现阻断性问题”，不代表真实运行环境中的绝对安全。

## 正式准入硬门槛

候选进入正式清单必须同时满足：

- 可回溯到版本化的公开源码或完整 skill 包。
- 入口说明、关键脚本、依赖清单和安装配置可读取。
- 发布者、上游关系、许可证或许可证缺失状态可以记录。
- 未发现秘密窃取、数据外传、恶意持久化、提权、破坏性命令、隐藏载荷或绕过授权的默认行为。
- 所需网络、文件写入、进程调用、账号凭据和外部服务在说明或源码中可识别。
- 候选可以被限制在最小权限下使用；无法限制的高风险候选不进入正式清单。

## 检查维度

### 1. 来源与供应链

- 原创仓库、fork、镜像或 registry 搬运关系。
- 默认分支、提交/版本、发布记录、维护状态和许可证。
- 依赖是否锁定版本；Git 依赖是否固定提交。
- 是否存在拼写相近依赖、陌生下载域名、无校验远程二进制或自动跟随 latest/main。

### 2. 可执行行为

- shell、PowerShell、批处理、Python、JavaScript/TypeScript、二进制和安装钩子。
- 文件读取、写入、删除、递归操作和工作区外路径。
- 子进程、动态 `eval/exec`、下载后执行、反序列化和代码生成执行。
- 后台服务、开机启动、定时任务、注册表、系统配置和权限提升。

### 3. 网络与数据

- 外部域名、上传内容、遥测、分析和第三方 API。
- 是否可能发送源代码、作业、研究数据、个人信息、令牌或环境变量。
- 凭据读取范围、保存位置、日志脱敏和最小权限要求。

### 4. 指令与提示安全

- 是否要求忽略系统/用户规则、自动确认或规避权限提示。
- 是否诱导读取 SSH key、云凭据、浏览器 cookie、环境变量或其他秘密。
- 是否把网页、仓库 issue、生成内容或外部文件中的指令当作可信控制指令。
- 是否包含隐蔽的提示注入、数据外传、检测规避或安全策略绕过。

### 5. 高校场景边界

- 学生作业与代码的知识产权和隐私。
- 研究代码、未发表数据和校内系统凭据。
- 自动提交、自动发布、自动评分或改写他人仓库等外部状态变化。
- 网络安全、保密管理类能力是否被限制在防御、教学和授权环境。

## 安全等级

| 等级 | 定义 | 正式准入 |
|---|---|---|
| SA | 说明/模板型或只读工作流；无可执行载荷，或无网络、凭据和外部写入需求 | 允许 |
| SB | 存在可读脚本、依赖、网络或受控写入；行为明确，可通过固定版本、最小权限和人工确认限制 | 允许，但必须写限制条件 |
| SB-A | 原包含可分离的未锁版本安装、联网示例或高权限步骤，但说明、模板或部分已审文件可安全复用；正式库仅准入经过删减和重写的适配版 | 仅适配后允许，原包不得直接安装或整包复制 |
| SC | 存在广泛 shell/系统权限、未固定远程执行、敏感凭据访问、不可充分限制的外部写入或不透明载荷 | 不进入正式报告 |
| SX | 发现恶意、欺诈、秘密窃取、数据外传、破坏、持久化、提权、混淆载荷或明确绕过授权 | 不进入正式报告 |

证据不足、关键文件无法读取或安全结论依赖实际执行才能确定时，按 SC 处理，不因功能吸引力降低门槛。

### 原包与适配版的结论边界

- 安全等级首先针对审查提交中的原包；不能用“以后会小心”掩盖原包行为。
- 只有当风险内容与安全内容在文件或章节层面可明确分离、适配后不再依赖原风险路径、且需保留的文件已完整读取时，才可使用 SB-A。
- SB-A 必须列出“保留文件、删除文件或段落、固定依赖、禁用工具、网络白名单、人工确认点”。缺少任一项按 SC 处理。
- `curl | shell`、未固定 `npx -y`、自动读取凭据、自动付费提交、默认发布/推送等行为，不得被复制到适配版。
- Excel 和 Word 中的 SB-A 条目必须醒目标注“仅适配后使用”，地址仍指向原始上游以便追溯，但不得表述为可直接安装。

## 静态审查记录字段

- 候选 ID、名称、来源平台、canonical source、审查提交/版本和日期。
- 可执行文件数量与类型；安装钩子和依赖文件。
- 网络端点、文件系统行为、进程调用、凭据和外部写入。
- 指令安全观察、供应链观察、许可证和维护状态。
- 安全等级、准入结论、限制条件、未验证部分和证据位置。

## 运行验证

运行验证不属于本协议默认范围。只有用户明确指定候选后，才在临时隔离目录、无真实凭据、无校内数据、网络最小化和可回滚条件下另行设计测试。
