# 研究生学科与本科专业 Skills 标签映射设计

日期：2026-08-16
状态：已完成会话设计确认，待用户审核书面规格

## 1. 背景

项目现有学科分类来源混合了本科专业类与研究生一级学科口径，不能稳定支持 Skills 的学科标签继承和双向检索。本设计建立一套基于教育部现行目录的、可审计的本科专业与研究生学科相关性映射。

映射服务于 Skills 学科标签与检索，不用于招生资格、报考条件、推免、调剂、学位授予或培养方案认定，也不得表述为教育部发布的官方升学对应关系。

## 2. 目标与范围

### 2.1 目标

- 完整收录教育部《普通高等学校本科专业目录（2026年）》中的全部 883 种本科专业。
- 完整收录研究生端全部学术学位一级学科和专业学位类别，并纳入教育部正式调整文件形成现行口径。
- 建立可解释、分等级、多对多的本科专业—研究生学科关系。
- 同时生成本科到研究生、研究生到本科的双向索引。
- 为 Skills 提供默认标签、扩展检索和跨学科召回依据。
- 保留两端无对应关系的目录项和明确状态，不只输出匹配成功项。

### 2.2 边界

- 不将相关性映射解释为官方升学通道。
- 不因名称相似直接判定核心对应。
- 不强制每个本科专业同时拥有学术学位和专业学位映射。
- 军事学目录关系可以保留，但不得生成 Skills 标签，也不得参与后续 Skills 检索和推荐。
- 目录事实与项目派生判断分栏保存，派生判断不得覆盖官方名称、代码和目录层级。

## 3. 权威来源与版本管理

本科端以教育部《普通高等学校本科专业目录（2026年）》为主来源。研究生端以《研究生教育学科专业目录（2022年）》为基础，并应用其后教育部、国务院学位委员会正式发布的调整文件。

工作簿必须记录：

- 文件或通知名称；
- 发布机构；
- 发文日期与目录版本；
- 访问日期；
- 官方原始网址；
- 适用范围；
- 是否为基础目录或后续调整；
- 本次采用或不采用的原因。

项目现有 `国内大学本科专业目录.xlsx` 只用于历史差异核对，不作为最终名称、代码和目录有效性的权威来源。

## 4. 工作簿结构

最终交付为一份独立 `.xlsx` 工作簿，至少包含以下工作表。

### 4.1 使用说明与版本

记录用途、非用途、目录版本、来源、访问日期、映射等级、标签行为、军事学限制和更新机制。

### 4.2 本科专业目录_2026

完整保留本科门类、专业类和具体专业。核心字段包括：本科门类代码、本科门类名称、专业类代码、专业类名称、专业代码、专业名称、目录属性、可授学位门类、修业年限、来源记录标识。

代码按文本保存，保留前导零及 `T`、`K` 等后缀。

### 4.3 研究生学科目录

同时保留学术学位一级学科和专业学位类别。核心字段包括：研究生门类代码、研究生门类名称、学科或类别代码、名称、对象类型、可授学位或备注、目录状态、来源记录标识。

对象类型只能取“学术学位一级学科”或“专业学位类别”。

### 4.4 学科相关性映射主表

一行表示一条本科专业—研究生对象关系。核心字段包括：

- 映射标识；
- 本科专业代码和名称；
- 研究生对象代码、名称和类型；
- 关系等级；
- 是否为该研究生类型下的主映射；
- 关系依据；
- 映射理由；
- Skills 标签行为；
- 军事学限制；
- 生成方式；
- 复核状态；
- 置信度；
- 证据与来源；
- 备注。

### 4.5 本科专业反向索引

以全部 883 种本科专业为入口，汇总学术学位主映射、专业学位主映射、其他核心关系、强相关关系、延伸关系、标签行为和零映射状态。

### 4.6 研究生学科反向索引

以全部研究生一级学科和专业学位类别为入口，汇总对应本科专业，并保留“无直接对应本科专业”的研究生对象。

### 4.7 规则与字段字典

记录字段枚举、关系等级、关系依据、标签继承规则、零映射状态、军事学规则和复核判据。映射、标签和质量检查规则必须在可见单元格中维护，不能只隐藏在生成脚本内。

### 4.8 来源台账

保存每个官方来源的名称、机构、发布日期、访问日期、网址、版本、范围和使用说明。

### 4.9 质量复核清单

列出尚未复核、确认无映射、缺少核心映射、仅有强相关或延伸关系、主映射超限、同名异义、跨门类异常、军事学标签泄漏、无效代码、重复关系和目录版本冲突。

### 4.10 统计总览

以公式汇总目录覆盖数、各等级映射数、两端零映射数、待复核数、军事学参考关系数和质量检查结果。统计必须能追溯到主数据和映射主表。

## 5. 关系模型

### 5.1 关系等级

| 等级 | 判定 | Skills 行为 |
|---|---|---|
| 主映射/核心对应 | 研究对象、主要知识体系或培养方向直接衔接 | 默认标签并参与精确检索 |
| 其他核心对应 | 同样具备直接衔接，但不是该类型下的唯一主映射 | 默认辅助标签 |
| 强相关 | 共享重要理论基础、方法技术或典型职业场景 | 参与扩展检索，不作为主标签 |
| 延伸相关 | 仅在部分交叉研究或应用场景中相关 | 仅在跨学科检索开启时召回 |
| 目录参考 | 保留关系但禁止标签与检索 | 仅用于目录查看 |

### 5.2 主映射约束

- 每个本科专业最多一个学术学位主映射。
- 每个本科专业最多一个专业学位主映射。
- 不能为了满足数量要求强行设置主映射。
- 没有合适对象时保留零映射状态及原因。

### 5.3 关系依据

关系依据可以多选，但必须至少有一项：

- 主要研究对象；
- 核心知识基础；
- 主要研究或实践方法；
- 关键技术体系；
- 典型职业或行业场景；
- 培养出口；
- 教育部目录或正式说明中的明确衔接；
- 跨学科应用关系。

名称和关键词仅用于发现候选，不能单独成为正式映射依据。

## 6. 零映射与状态模型

两端所有目录项必须保留。除映射成功外，允许以下状态：

- 已依据规则复核；
- 高置信度候选；
- 存在歧义，建议学科专家复核；
- 已确认无直接对应；
- 尚未完成复核；
- 军事学限制；
- 目录版本差异待处理。

本科专业没有合适研究生对象时，在本科反向索引中保留并标记“无合适研究生对应”。研究生对象没有本科对应时，在研究生反向索引中保留并标记“无直接对应本科专业”。

“尚未完成复核”“已确认无映射”“因军事学规则仅保留目录参考”必须使用不同状态，不得混写。

## 7. 军事学边界

- 保留军事学研究生目录项及合理的本科—研究生目录关系。
- 军事学相关关系的 Skills 标签行为固定为“目录参考”。
- 默认标签、辅助标签、扩展检索和跨学科召回字段均不得启用。
- 质量检查必须扫描军事学关系的标签泄漏。
- 后续 Skills 调研、分类、检索、推荐和入库流程不得消费军事学映射。

## 8. 生成与复核流程

1. 采集并固定官方目录和调整文件。
2. 建立本科和研究生标准化主数据，保留官方名称、代码和层级。
3. 使用名称、代码层级、目录关系和学科规则生成候选映射。
4. 对同名异义、新增专业、交叉学科和跨门类关系单独复核。
5. 判定关系等级、主映射、关系依据、标签行为、置信度和复核状态。
6. 补写两端零映射状态。
7. 生成双向索引、统计总览和质量复核清单。
8. 执行结构、数量、公式、逻辑和可读性验证。

自动生成只负责提出候选和执行一致性规则，不得将未经复核的候选标记为正式核心映射。

## 9. 异常与歧义处理

- 同名不同义：依据门类、知识体系和研究对象区分，无法确定时进入专家复核。
- 一个本科专业对应多个一级学科：保留多对多关系，但严格限制主映射数量。
- 一个研究生对象覆盖大量本科专业：保留反向索引并检查是否因过宽关键词造成误配。
- 新增交叉专业：允许多个核心或强相关关系，映射理由必须说明交叉维度。
- 目录调整造成代码或名称变化：保留来源版本和调整说明，不静默覆盖。
- 缺少直接对应：保留零映射状态，不用弱相关关系填补空白。
- 军事学：无论相关性高低，标签行为均固定为目录参考。

## 10. 质量检查与验收标准

只有同时满足以下条件，工作簿才可交付：

- 本科主数据覆盖 2026 目录全部 883 种专业；
- 研究生全部一级学科和专业学位类别均被收录；
- 两端每个目录代码唯一，官方代码按文本保存；
- 两端零映射目录项均在反向索引中保留；
- 每条映射的本科和研究生代码均能在主数据表中解析；
- 不存在重复的本科代码—研究生对象类型—研究生代码关系；
- 每个本科专业每种研究生对象类型最多一个主映射；
- 军事学关系不存在任何可消费的 Skills 标签或检索行为；
- 主表、双向索引和统计总览数量相互一致；
- 质量复核清单能够识别所有约定异常；
- 关键统计与代表性映射完成抽查；
- 工作簿无明显公式错误、空白默认工作表或严重排版问题；
- 所有工作表至少完成一次渲染和视觉检查。

## 11. 更新机制

- 本科专业目录更新时，先更新本科主数据，再标记受影响映射为“目录版本差异待处理”。
- 研究生目录或调整文件更新时，同样保留旧来源记录，并对受影响关系重新复核。
- 映射结论修订必须保留修订日期、原结论、修订后结论和理由。
- 后续 Skills 系统只读取复核状态满足项目要求且非军事学限制的关系。

## 12. 交付物

- 一份研究生学科与本科专业相关性映射 `.xlsx` 工作簿；
- 工作簿内置完整来源台账、字段字典、双向索引、零映射记录、统计总览和质量复核清单；
- 不额外把未经专家确认的映射包装为教育部官方对应关系。
