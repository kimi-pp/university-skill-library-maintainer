# 0301 法学类学科专属 Skill 调研 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 独立完成 0301 法学类学科专属 Skill 的公开来源检索、通用库排除、固定版本静态审查和 Excel、Word、Markdown 知识库交付。

**Architecture:** 采用“法学专业—八个能力小类—独立候选—固定上游证据”结构。发现页面只提供线索，正式条目必须回到版本化公开上游；所有数据保存在 0301 独立文件中，不与 0305 或 1304 混合。

**Tech Stack:** ClawHub、GitHub、Hugging Face Spaces、公开搜索和开源平台，Markdown/JSON/JSONL，静态文件与数据流审查，工作区内置 Spreadsheet 与 Documents 工具链。

## Global Constraints

- 唯一学科范围：`0301 法学类`，覆盖法学、知识产权、监狱学、信用风险管理与法律防控。
- 只收录学科专属 Skill；现有 `GH-*`、`FD-*` 及实质相同的通用 Skill 硬排除。
- 默认检索顺序：ClawHub → GitHub → Hugging Face Spaces；其他公开来源仅作补充发现，正式结论必须回溯到可固定版本上游。
- 本轮不安装、不运行候选，不登录候选服务，不上传案件、合同、证据、学生信息或其他真实敏感资料。
- 正式推荐只允许 SA、SB 且验证状态达到“全部通过（未实测）”；SB-A 原包只进入 0301 内部适配池。
- 无明确许可证、无法固定版本、关键内容不可读、SC、SX、通用或实质重复候选不进入正式交付。
- 法律输出只能作为学习、研究或专业人员复核的草案，不得表述为最终法律意见、司法结论或自动高影响决定。
- 正式交付只包含 0301 独立 Excel、独立 Word 和独立 Markdown 知识库；不得生成跨学科合并文件。
- 面向用户的文字必须让非计算机背景读者直接理解，且明确所有候选未安装、未运行。
