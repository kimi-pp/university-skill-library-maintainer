# 0305 马克思主义理论类学科专属 Skill 调研 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 独立完成 0305 马克思主义理论类学科专属 Skill 的公开来源检索、通用库排除、固定版本静态审查和 Excel、Word、Markdown 知识库交付。

**Architecture:** 采用“两个专业—八个能力小类—独立候选—可核对文本证据”结构。候选必须含本学科专用经典文献、版本校核、概念框架或思政教学流程；所有研究数据和成果与其他学科分开保存。

**Tech Stack:** ClawHub、GitHub、Hugging Face Spaces、公开搜索和开源平台，Markdown/JSON/JSONL，版本与引文静态核验，工作区内置 Spreadsheet 与 Documents 工具链。

## Global Constraints

- 唯一学科范围：`0305 马克思主义理论类`，覆盖马克思主义理论、思想政治教育。
- 只收录学科专属 Skill；通用论文写作、润色、综述、检索、引用、教学和社会分析 Skill 硬排除。
- 默认检索顺序：ClawHub → GitHub → Hugging Face Spaces；其他公开来源仅作补充发现，正式结论必须回溯到可固定版本上游。
- 本轮不安装、不运行候选，不登录候选服务，不上传学生信息、未公开课程材料、调研数据或研究草稿。
- 正式推荐只允许 SA、SB 且达到“全部通过（未实测）”；SB-A 原包只进入 0305 内部适配池。
- 无明确许可证、无法固定版本、关键内容不可读、SC、SX、通用或实质重复候选不进入正式交付。
- 原文、译文、编者说明、模型概括和研究者解释必须分开；引文必须能回到版本和定位证据。
- 对理论、历史、社会和政策材料的概括保持中性、可核查，不把模型推断或项目宣传当成权威结论。
- 正式交付只包含 0305 独立 Excel、独立 Word 和独立 Markdown 知识库；不得生成跨学科合并文件。
- 面向用户的文字必须让非计算机背景读者直接理解，且明确候选未安装、未运行。
