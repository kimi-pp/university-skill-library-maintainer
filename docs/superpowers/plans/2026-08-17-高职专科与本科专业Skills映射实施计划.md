# 高职专科与本科专业 Skills 映射 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于教育部截至 2026 年 7 月更新的职业教育专业目录，为全部 811 个高职专科专业建立到 2026 年 883 个普通本科专业的可审计双层相关性映射，并输出 Skills 标签与检索可消费的数据包和工作簿。

**Architecture:** 在独立数据域中冻结教育部 2021 基础目录、2025 增补、2026 更新后完整目录及用户输入分类表，解析为高职专科主数据和 97 个专业类的 Skills 辅助分类。通过“97 类保守候选种子＋具体专业词项规则＋专业级覆盖决定”产生候选，每个高职专业用复核台账穷尽接受或拒绝候选；再由单一构建器生成正式映射、双向索引、零映射、97 类聚合和 QA，最后用 `@oai/artifact-tool` 创建并验证一份 11 表工作簿。

**Tech Stack:** Windows PowerShell、绑定版 Python 3 标准库、绑定版 Node.js、`@oai/artifact-tool`、Node `assert`、Python `unittest`、Git。

## Global Constraints

- 高职专科现行目录以教育部“职业教育专业目录（2021年）（更新时间：2026年7月）”为最终有效集合，并以 2021 基础目录和 2025、2026 正式增补文件保全版本沿革。
- 现行高职专科目录必须覆盖 19 个专业大类、97 个专业类、811 个专业代码；代码为六位基础码，49 个国家控制专业保留官方 `K` 后缀；2026 年新增专业须标注“目录发布于 2026 年，自 2027 年起招生”。
- 用户输入 `D:/高校AI工作台/高职高专Skills领域分类表.xlsx` 只提供 19 大类、97 专业类及 Skills 领域辅助分类，不提供具体专业事实，也不作为专业相关性的单独证据。
- 本科端只复用 `06_过程记录/discipline_mapping/catalogs/undergraduate_2026.json`，必须精确覆盖 13 个门类、92 个专业类、883 个本科专业。
- 所有代码按文本保存，保留前导零及本科代码中的 `T`、`K` 等后缀。
- 正式关系粒度只能是“高职专科具体专业—本科具体专业”；97 专业类汇总只能由已接受的具体专业关系派生。
- 每个高职专业最多一个主映射；不存在合适核心关系时保留“无直接本科对应”，完全没有接受关系时另记“无接受关系”。
- 关系等级只能是“主映射/核心对应”“其他核心对应”“强相关”“延伸相关”“目录参考”。
- Skills 行为只能是“默认标签”“默认辅助标签”“扩展检索”“跨学科召回”“仅目录查看”“无”。
- 武器、弹药、军用装备、兵器制造或明确军事作战对象只能使用“目录参考＋仅目录查看＋非主映射＋不可消费”。
- 公安、司法、应急和一般公共安全专业不得仅因安全主题被自动归入军事限制，必须依据培养对象判定。
- 名称相似、代码邻近或 Skills 领域相同只能发现候选，不能单独证明核心对应。
- 每个高职专业必须且只能有一条复核台账；其全部候选必须恰好进入接受或拒绝集合之一。
- 交付时不得存在“尚未完成复核”的高职专业，`qa.blocking` 必须为 0。
- 映射仅服务 Skills 标签与检索，不得宣称专升本资格、招生对应、课程互认、学分转换、学历衔接或学位等同。
- 不修改现有研究生—本科映射数据包、脚本和 `研究生学科与本科专业Skills相关性映射.xlsx`。
- 只使用 `load_workspace_dependencies` 返回的绑定版运行时和依赖，不安装系统或仓库第三方包。
- 所有工作簿导入、创建、编辑、导出和渲染使用 `@oai/artifact-tool`，不使用 `openpyxl`、`xlsxwriter` 或 `pandas.ExcelWriter`。
- 第一次工作簿创建命令前必须且只能成功运行一次 `mark_artifact_operation_started.mjs --operation-kind create --expected-output-count 1 --output-format xlsx`。
- 最终文件固定保存到 `D:/高校AI工作台/outputs/01a004e5-65dc-7c52-bd8c-7e29e9e058bc/高职专科专业与本科专业Skills相关性映射.xlsx`，不生成第二个工作簿变体。
- 当前 `main` 工作区包含大量用户未提交内容；实施使用独立 worktree，每次提交只暂存本任务明确列出的文件。
