# 1304 美术学类学科专属 Skill 调研 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 独立完成 1304 美术学类学科专属 Skill 的公开来源检索、通用库排除、固定版本静态审查和 Excel、Word、Markdown 知识库交付。

**Architecture:** 采用“六个专业—九个能力小类—独立候选—作品与权利证据”结构。通用图像生成和设计工具首先排除，只有内含美术研究、创作教学、馆藏保存、书画或雕塑专用流程的候选进入审查。

**Tech Stack:** ClawHub、GitHub、Hugging Face Spaces、公开搜索和开源平台，Markdown/JSON/JSONL，图像与三维工作流静态审查，工作区内置 Spreadsheet 与 Documents 工具链。

## Global Constraints

- 唯一学科范围：`1304 美术学类`，覆盖美术学、绘画、雕塑、摄影、书法学、中国画。
- 只收录学科专属 Skill；通用图像生成、修图、设计、幻灯片、作品集排版、OCR、元数据和三维工具硬排除。
- 默认检索顺序：ClawHub → GitHub → Hugging Face Spaces；其他公开来源仅作补充发现，正式结论必须回溯到可固定版本上游。
- 本轮不安装、不运行候选，不登录候选服务，不上传未公开作品、学生作品、馆藏高清图、人物影像或三维扫描。
- 正式推荐只允许 SA、SB 且达到“全部通过（未实测）”；SB-A 原包只进入 1304 内部适配池。
- 无明确许可证、无法固定版本、关键内容不可读、SC、SX、通用或实质重复候选不进入正式交付。
- 必须检查作品版权、署名、人格权、馆藏条款、训练数据、作品来源和原文件覆盖风险。
- 艺术品来源、归属和真伪输出只能作为线索，不能替代鉴定、馆藏或版权专业人员结论。
- 正式交付只包含 1304 独立 Excel、独立 Word 和独立 Markdown 知识库；不得生成跨学科合并文件。
- 面向用户的文字必须让非计算机背景读者直接理解，且明确候选未安装、未运行。
