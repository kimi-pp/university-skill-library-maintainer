# 课程设计、教学材料与教学评估全网调研 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立“06 课程设计、教学材料与教学评估”的十二个小分类技能库，完成全网公开来源发现、固定版本静态核验、教育安全审查、知识库与 26 份正式交付文件。

**Architecture:** 采用“大分类 → 小分类 → 唯一主分类技能”的三级数据组织方式，以一份规范化 JSON 目录作为 Excel、Word 和 Markdown 知识库的共同数据源。发现记录、固定版本来源快照、安全审查与正式交付分层保存，确保落选项不进入正式文件，并能从每条结论回到版本、许可证和安全证据。

**Tech Stack:** PowerShell、Python 3、Node.js、`@oai/artifact-tool`、`python-docx`、Markdown、JSON/JSONL、公开网页与公开代码托管平台。

## Global Constraints

- 调研范围是截至核验日期可公开访问的全网来源，包括但不限于 GitHub、GitLab、Gitee、Codeberg、SourceHut、Hugging Face、公开技能目录、高校和教学技术组织页面。
- 市场卡片、榜单和搜索摘要只用于发现；正式证据必须回到固定版本公开源文件或可完整阅读的技能包。
- 本轮不安装、不运行候选技能，不登录候选服务，不上传真实作业、成绩、个人信息或未公开论文。
- 每个正式技能只有一个主要小分类，交叉能力只记辅助功能标签。
- 正式收录仅允许 SA、SB 和 SB-A；SB-A 只描述适配后方案，SC、SX、重复项和其他落选项只留内部记录。
- 作业批改、课程论文与毕业论文评阅、期刊与会议论文同行评审分别使用 06-06、06-11、06-12，不混写。
- 所有正式说明必须让非计算机背景的教师、助教、教学管理人员和学生直接理解。
- 正式交付固定为 13 个 Excel 和 13 个 Word，共 26 个文件；每个 Excel 固定有“使用说明、AI技能清单、分类统计、来源清单”四个工作表。
- Excel 和 Word 必须经过实际渲染检查；静态检查不能写成已成功运行。
- 保留工作区现有其他任务成果；每次提交只暂存本任务列出的文件。
