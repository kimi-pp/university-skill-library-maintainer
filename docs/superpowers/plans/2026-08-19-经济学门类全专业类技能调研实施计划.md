# 经济学门类全专业类 Skill 调研 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以教育部 2026 本科专业目录为基线，完成经济学门类 4 个专业类、30 个专业的四社区联网 Skill 调研、功能级去重、静态核验、筛选评分和 4 组 Word/Excel 正式交付。

**Architecture:** 使用一个新的 `06_过程记录/economics_2026-08-19` 过程根目录保存范围合同、专业画像、查询台账、原始响应、固定版本快照、去重与准入结果。所有正式文件先写入 staging，由统一交付合同核对索引、正式数据、Word、Excel、视觉证据和哈希后再发布到 `05_交付物/02_经济学_专业类技能调研`。现有工学脚本只作为已验证模式参考，不改写工学成果。

**Tech Stack:** 项目内 Python、PowerShell、GitHub CLI、公开 HTTP API；工作区依赖加载器提供的 Python/Node；`@oai/artifact-tool` 生成和检查 XLSX；`python-docx` 与 Documents skill 的 `render_docx.py` 生成和渲染 DOCX；`unittest` 与 Node assertions 做回归测试。

**Spec:** `docs/superpowers/specs/2026-08-19-经济学门类全专业类技能调研-design.md`

## Global Constraints

- 范围固定为教育部《普通高等学校本科专业目录（2026年）》中的 `02 经济学`：4 个专业类、30 个专业。
- 来源平台固定为 SkillHub、ClawHub、GitHub、Hugging Face Spaces；既有快照只作历史种子，本轮结论必须带 2026-08-19 起的联网证据和访问日期。
- 每个专业必须具有专业画像、双语检索矩阵和四平台覆盖记录；正式结果为 0 时必须执行专项补查。
- 同一上游、镜像、fork、跨平台搬运或实质功能相同的 Skill 只保留一个正式条目；跨专业类只设一个主归档。
- 正式项必须满足四项准入、固定版本、许可证、专业相关性和静态干运行核验，安全等级只允许 SA 或 SB。
- 默认不安装、不运行候选 Skill，不登录候选服务，不使用真实密钥或校内敏感数据。
- 外部 API、本地专业软件、本地脚本/插件接口必须分列记录，禁止相互推导。
- 质量评分固定为 `min(5, 1 + 加分项数量)`，评分不能抵消任何硬门槛。
- 正式交付固定为 4 个专业类目录，每类 1 份 Word 和 1 份 Excel，共 8 个文件；Excel 固定四张工作表。
- XLSX 必须使用工作区依赖加载器提供的 Node 与 `@oai/artifact-tool` 生成；禁止使用 openpyxl、xlsxwriter 或 pandas.ExcelWriter 写工作簿。
- DOCX 必须使用工作区依赖加载器提供的 Python 环境，采用 `compact_reference_guide` 预设和明确的首页头部模板，并执行逐页渲染检查。
- 正式目录只在 staging 全部验收通过后发布；不得覆盖不属于本轮的现有文件。
- 工作区当前包含用户既有未提交改动；每次提交只暂存本任务明确列出的文件。

```python
CLASS_COUNTS = {"0201": 11, "0202": 3, "0203": 12, "0204": 4}

def load_economics_scope(catalog_path: Path) -> dict:
    records = json.loads(catalog_path.read_text(encoding="utf-8"))["records"]
    selected = [row for row in records if row["category_code"] == "02"]
    classes = []
    for code in sorted(CLASS_COUNTS):
        rows = sorted((r for r in selected if r["class_code"] == code), key=lambda r: r["major_code"])
        if len(rows) != CLASS_COUNTS[code]:
            raise ValueError(f"{code} count mismatch: {len(rows)}")
        classes.append({"code": code, "name": rows[0]["class_name"], "major_count": len(rows), "majors": rows})
    if sum(c["major_count"] for c in classes) != 30:
        raise ValueError("economics major total must be 30")
    return {"category_code": "02", "category_name": "经济学", "classes": classes}
```
