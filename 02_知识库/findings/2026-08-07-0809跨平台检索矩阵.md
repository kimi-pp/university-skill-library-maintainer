# 0809 计算机类跨平台 Skill 检索矩阵

## 平台路线

| 来源类型 | 平台 | 发现方式 | 正式证据要求 |
|---|---|---|---|
| 代码托管 | GitHub | repository/code search、topics、相邻目录 | 具体 skill 目录、入口文件、提交/分支 |
| 代码托管 | GitLab | projects/blobs 搜索、公开项目 | 公开项目内入口与版本化文件 |
| 代码托管 | Codeberg | repository 搜索、公开目录 | 公开仓库与具体 skill 路径 |
| 代码托管 | Gitee | 项目/代码搜索、中文生态词 | 公开仓库与具体 skill 路径 |
| 代码托管 | SourceHut | 项目页、邮件列表/仓库索引、搜索引擎辅助 | 公开仓库与版本化文件 |
| 开放仓库 | Hugging Face | Spaces/models/datasets 搜索、仓库文件 | 必须有 agent skill 或可移植工作流，不把模型本身当 skill |
| Skill registry | 开放 registry/市场/精选集合 | 分类、关键词、生态标签 | 必须回溯 canonical public source；registry 页面只作发现证据 |

## 静态安全检索与扫描词

- 进程/动态执行：`subprocess`, `os.system`, `exec`, `eval`, `child_process`, `shell=True`
- 下载执行：`curl`, `wget`, `Invoke-WebRequest`, `download`, `latest`, `raw.githubusercontent`
- 文件与破坏：`rm -rf`, `Remove-Item -Recurse`, `shutil.rmtree`, `unlink`, `format`, `diskpart`
- 凭据与秘密：`SSH`, `.env`, `TOKEN`, `API_KEY`, `credential`, `cookie`, `keychain`
- 持久化/提权：`sudo`, `administrator`, `registry`, `schtasks`, `cron`, `startup`
- 网络/外传：`requests.post`, `fetch`, `webhook`, `telemetry`, `analytics`, `upload`
- 提示风险：`ignore previous`, `bypass`, `do not ask`, `auto approve`, `exfiltrate`
- 供应链：`preinstall`, `postinstall`, `setup.py`, `pyproject.toml`, `package.json`, lockfile、Git SHA

以上关键词只用于定位审查点；命中不自动等于恶意，必须结合上下文判断。

## 去重键与停止规则

- 去重键：`canonical source + skill path + version family`。
- fork/镜像/registry 搬运不重复计数；功能明显不同的同仓库 skill 分别记录。
- 每个能力群完成平台主检索、相邻目录扫描和两轮补充检索。
- 两轮补充检索均未发现能通过安全准入且功能实质不同的新候选后，判定该能力群达到当前检索饱和。
