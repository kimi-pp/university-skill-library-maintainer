# PDF 综合处理（Anthropic）（pdf）

> 读取、生成、转换、拆分、合并和 OCR PDF。

## 功能说明

提供文本表格提取、图片提取、表单、水印、旋转和加解密等常见 PDF 操作路线。

## 适用对象与场景

- 适用角色：学生、教学人员、科研人员、行政人员
- 典型场景：论文阅读、扫描件 OCR、材料合并与归档
- 功能标签：PDF、提取、合并、拆分、OCR、表单

## 接入判断

- 兼容等级：B
- 适配建议：使用 Codex 可用的 PDF 工具替换命令路径。
- 依赖条件：Poppler、Python PDF/OCR 工具
- 风险与边界：OCR 和复杂版面可能丢失结构；加密文件需合法权限。
