# 科研演示文稿工作流（scientific-slides）

> 为研究报告、会议和答辩构建科学演示文稿。

## 功能说明

提供叙事结构、时间分配、设计模板和视觉验证，可输出 PowerPoint 或 LaTeX Beamer。

## 适用对象与场景

- 适用角色：学生、科研人员、教学人员
- 典型场景：组会、论文分享、学术会议、开题与答辩
- 功能标签：科研汇报、答辩、会议演讲、Beamer

## 接入判断

- 兼容等级：A
- 适配建议：可直接作为内容与视觉规则；图像生成依赖按需替换。
- 依赖条件：PowerPoint 或 LaTeX；部分流程引用图像生成工具
- 风险与边界：自动生成视觉素材需核验版权和科学准确性。
- 关联说明：无
