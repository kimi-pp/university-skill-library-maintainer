# Markdown 多格式导出（markdown-exporter）

> 将 Markdown 导出为多种办公、数据和代码格式。

## 功能说明

支持 DOCX、PPTX、XLSX、PDF、HTML、IPYNB、CSV、JSON、XML，并可提取代码块。

## 适用对象与场景

- 适用角色：学生、教学人员、科研人员、行政人员
- 典型场景：一份 Markdown 多渠道发布、报告与数据文件导出
- 功能标签：Markdown、DOCX、PPTX、XLSX、PDF、导出

## 接入判断

- 兼容等级：B
- 适配建议：安装项目依赖并按目标格式选择导出器。
- 依赖条件：项目 CLI/Dify 插件及各格式依赖
- 风险与边界：多格式覆盖不代表版式一致；每种目标都需单独验收。
