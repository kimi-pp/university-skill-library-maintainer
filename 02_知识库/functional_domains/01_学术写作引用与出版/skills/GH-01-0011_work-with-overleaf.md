# Overleaf 协作桥接（work-with-overleaf）

> 把 Overleaf 项目接入本地论文检查和修改流程。

## 功能说明

支持 Overleaf Git、GitHub 同步和 ZIP 三种路径，强调先拉取、差异检查、凭据保密和推送确认。

## 适用对象与场景

- 适用角色：科研人员、研究生
- 典型场景：课题组 Overleaf 稿件本地预检、同步修改
- 功能标签：Overleaf、LaTeX、同步、Git、ZIP

## 接入判断

- 兼容等级：B
- 适配建议：根据账号权限选择同步路径；所有回写都要求单独确认。
- 依赖条件：Overleaf 账号；可选 Git 权限或 ZIP
- 风险与边界：令牌与未发表稿件敏感；错误同步可能覆盖协作内容。
- 关联说明：无
