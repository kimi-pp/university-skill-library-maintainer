# 多平台学术检索框架（academic-search）

> 以平台选择矩阵和分层策略组织学术搜索。

## 功能说明

仓库包含 OpenAI agent 配置、检索框架图、参考资料和脚本，强调先做前置检查，再按问题类型选数据库和查询式。

## 适用对象与场景

- 适用角色：学生、科研人员、图书馆人员
- 典型场景：跨学科文献查找、检索策略教学和复杂查询规划
- 功能标签：学术检索、平台选择、检索策略、中文指南
