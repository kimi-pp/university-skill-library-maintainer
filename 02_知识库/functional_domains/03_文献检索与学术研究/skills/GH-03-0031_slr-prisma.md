# PRISMA 2020 系统综述向导（slr-prisma）

> 按 PRISMA 2020 引导用户完成系统文献综述。

## 功能说明

覆盖二十七项清单、访谈式范围确定、数据库策略、纳排标准、偏倚评估、叙述综合、Word 手稿和带注释流程图；不做统计合并。

## 适用对象与场景

- 适用角色：科研人员、研究生、教学人员
- 典型场景：系统综述课程、毕业论文、PRISMA 报告审计
- 功能标签：PRISMA 2020、系统综述、纳排、流程图、APA
