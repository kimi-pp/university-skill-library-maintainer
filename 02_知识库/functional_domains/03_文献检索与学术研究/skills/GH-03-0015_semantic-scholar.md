# Semantic Scholar 引文图谱（semantic-scholar）

> 跨学科检索 Semantic Scholar 并遍历引用和参考文献。

## 功能说明

涵盖论文、作者、推荐和批量接口，适合引用链追踪和文献计量初筛。

## 适用对象与场景

- 适用角色：学生、科研人员、图书馆人员
- 典型场景：种子论文扩展、相关论文推荐、引文网络
- 功能标签：Semantic Scholar、引文图、作者、推荐、文献计量

## 接入判断

- 兼容等级：B
- 适配建议：映射到 paper-lookup 或 Semantic Scholar API。
- 依赖条件：Semantic Scholar API；高频请求可能需要密钥
- 风险与边界：引用数和论文合并记录会更新，不能作为唯一评价依据。
- 关联说明：无
