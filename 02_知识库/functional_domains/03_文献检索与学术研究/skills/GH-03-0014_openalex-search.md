# OpenAlex 开放学术图谱检索（openalex-search）

> 通过 OpenAlex 查询论文、作者、机构和开放引文数据。

## 功能说明

提供实体检索、过滤和概念映射，适合机构分析、作者概况和开放书目研究。

## 适用对象与场景

- 适用角色：科研人员、图书馆人员、科研管理人员
- 典型场景：机构科研分析、作者画像、主题与引文网络
- 功能标签：OpenAlex、作者、机构、概念、开放引文
