# arXiv 预印本检索（arxiv-search）

> 按主题、作者和分类检索 arXiv 预印本。

## 功能说明

解释 arXiv API 查询语法、学科代码和元数据字段，并区分预印本与正式期刊检索。

- 适用角色：学生、科研人员
