# 0301 法学类专业范围

日期：2026-08-12  
来源：项目《国内大学本科专业目录.xlsx》索引  
用途：限定 0301 学科专属 Skill 调研的专业边界

| 专业代码 | 专业名称 | 本轮重点任务 |
|---|---|---|
| 030101K | 法学 | 法律检索、案例分析、法源引用、法律文书、证据整理、模拟法庭和比较法务 |
| 030102 | 知识产权 | 知识产权法源、判例、权利检索、许可条款和侵权风险整理 |
| 030103 | 监狱学 | 法律政策资料、矫正与监狱治理案例、证据和合规材料整理；不得自动作出惩戒或个体处置决定 |
| 030104T | 信用风险管理与法律防控 | 信用与合规规则、合同和风险事项检查；不得自动作出授信或其他高影响决定 |

## 使用边界

- 只收录能从公开固定版本证明具有法律专用材料、步骤、规则或成果的 Skill。
- 通用写作、通用检索、通用引用、通用教学、通用办公和通用数据分析 Skill 不进入本学科正式成果。
- 输出只能作为学习、研究或专业人员复核的草案，不构成最终法律意见、司法结论、授信决定或惩戒决定。
- 同一 Skill 可以映射多个专业，但只能归入一个主要能力小类。
