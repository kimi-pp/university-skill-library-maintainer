# 1304 美术学类专业范围

日期：2026-08-12  
来源：项目《国内大学本科专业目录.xlsx》索引  
用途：限定 1304 学科专属 Skill 调研的专业边界

| 专业代码 | 专业名称 | 本轮重点任务 |
|---|---|---|
| 130401 | 美术学 | 美术史论、作品分析、艺术品编目、数字保存、展览与版权来源 |
| 130402 | 绘画 | 绘画观察、构图、色彩、材料与过程反馈 |
| 130403 | 雕塑 | 雕塑材料、三维采集、模型整理、尺寸记录和展示准备 |
| 130404T | 摄影 | 摄影作品研究、元数据、数字保存、展览和权利管理 |
| 130405 | 书法学 | 书体、款识、题跋、印章、笔法和版本研究 |
| 130406T | 中国画 | 笔墨、题材、款识、题跋、印章、材料和作品研究 |

## 使用边界

- 只收录能从公开固定版本证明具有美术研究、创作教学、艺术品编目保存、雕塑三维、书法或中国画专用流程的 Skill。
- 通用图像生成、修图、设计、演示、作品集排版、OCR、元数据和三维工具不进入正式成果。
- 来源、作者归属和真伪判断只作为线索整理，不能替代鉴定、馆藏或版权专业人员的结论。
- 同一 Skill 可以映射多个专业，但只能归入一个主要能力小类。
