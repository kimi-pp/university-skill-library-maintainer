# DISC-1304-0011 博物馆开放艺术图像检索与许可核对

- 原始名称：museum-art
- 主能力小类：1304-09 版权溯源
- 适用专业：130401 美术学、130402 绘画、130403 雕塑、130404 摄影、130405T 书法学、130406T 中国画、130407TK 实验艺术、130408TK 跨媒体艺术、130409T 文物保护与修复、130410T 漫画、130411T 纤维艺术、130412TK 科技艺术、130413TK 美术教育
- 适用人员：学生、教学人员、科研人员、馆藏与展览支持人员

## 它能帮您做什么

从多家博物馆开放接口检索高分辨率艺术图像，并逐件核对公有领域或开放许可标记。

## 使用前要准备什么

题材、艺术家或时期、用途、分辨率要求和许可边界。

## 会得到什么

馆藏图像候选、作品元数据、原始馆藏页、下载地址和逐件许可说明。

## 不能做什么

不同馆藏的权利标记不一致，必须逐件确认；不得把“开放馆藏”误写成所有作品都可自由使用。 只辅助研究、记录和方案草拟；作品真伪、来源权利、保存修复、市场价值和专业鉴定必须由合格人员复核。

## 安全与接入

- 安全等级：SB
- 使用难度：需要少量调整
- 文件行为：可把选定公开图像写入具体项目资产目录；不建立无来源的共享图片池。
- 网络与数据：会访问 Met、Cleveland、SMK、Rijksmuseum、NGA、AIC、Getty 等馆藏接口并下载公开图像；不上传用户材料。
- 账号凭据：大多数来源无需密钥；Smithsonian、Europeana 等部分来源可能需要免费 API 密钥。
