# 0301 法学类学科专属 Skill 调研启动记录

启动日期：2026-08-12

## 调研范围

- 一级学科：`0301 法学类`
- 专业：法学、知识产权、监狱学、信用风险管理与法律防控
- 能力小类：法律检索、案例裁判、法源引用、法律文书、证据整理、模拟法庭、合规风控、比较法务
- 来源顺序：ClawHub → GitHub → Hugging Face Spaces；完成默认平台后再使用其他公开来源补充发现

## 功能、用户和产出

- 目标功能：服务法学课程学习、案例研究、模拟实务、学术研究和高校法律专业支持。
- 适用人员：法学类学生、教师、科研人员，以及经过授权的高校法律与合规支持人员。
- 典型产出：法源清单、案例摘要、引证核对表、文书草案、证据目录、模拟庭审材料、合规检查表和法域对照表。

## 验证和安全边界

- 不安装、不运行候选，不输入真实案件、客户、合同、证据、学生或信用数据。
- 功能验证采用说明阅读、包内容检查和静态数据流推演。
- 正式候选只允许 SA、SB 且达到“全部通过（未实测）”。
- SB-A 原包只进入 0301 内部适配池；SC、SX 和证据不足项进入内部排除记录。
- 不推荐自动形成最终法律意见、司法决定、授信、惩戒或其他高影响决定。

## 通用库排除

现有 `GH-*`、`FD-*` 及实质相同的通用写作、检索、引用、办公、教学和数据分析 Skill 不进入 0301 正式数据。学科专属子 Skill 必须有独立入口和法律专用材料、规则或流程。
