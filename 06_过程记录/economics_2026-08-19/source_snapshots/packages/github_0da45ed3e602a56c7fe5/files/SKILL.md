# Alpha-X SKILLs

专业金融服务从业者的 AI 技能集合，适用于 A股、港股及中概股市场。

## 概述

本项目提供完整的金融服务领域 AI 技能，覆盖：
- **股票研究分析** - 盈利分析、首次覆盖、行业研究、公司一页纸
- **投资银行并购** - Teaser、CIM、买家名单、交易跟踪
- **财务建模分析** - DCF、可比公司、三表模型、LBO
- **私募股权投资** - 尽职调查、回报分析、价值创造
- **财富管理顾问** - 客户报告、资产配置、税务规划
- **量化交易策略** - 多因子选股、风险分析、组合管理
- **行情分析** - 交易回测、缠论分析、网格交易、市场建模

## 使用方式

### 直接调用具体技能

```
使用 skill: "earnings-analysis" 分析贵州茅台的最新季度业绩
```

```
使用 skill: "company-onepage" 分析宁德时代
```

```
使用 skill: "dcf-model" 为某公司构建 DCF 估值模型
```

### 通过命令调用

```
使用 commands/equity-research/earnings.md 分析 [公司] 的 Q3 2024 业绩
```

```
使用 commands/financial-analysis/dcf.md 构建 DCF 模型
```

### 调用量化交易智能体

```
使用 skill: "trading-agents" 对 [股票/行业] 进行量化研究分析
```

## 规范遵循

本项目遵循 [Agent Skills](https://agentskills.io/what-are-skills) 设计规范：

```
alpha-x-skills/
├── SKILL.md                    # 技能集合索引（本文件）
├── equity-research/            # 技能领域
│   └── [skill-name]/
│       ├── SKILL.md           # 技能定义
│       ├── references/        # 参考文档
│       ├── scripts/           # 可执行脚本
│       └── assets/           # 模板资源
├── financial-analysis/
├── investment-banking/
├── private-equity/
├── wealth-management/
├── market-analysis/
└── quantitative-trading/       # 量化交易智能体
    └── trading-agents/
        ├── [agent-name]/      # 各子智能体
        └── SKILL.md           # 智能体集合定义
```

## 贡献指南

添加新技能时：
1. 在对应领域目录下创建 `[skill-name]/`
2. 创建 `SKILL.md` 文件，包含 name、description
3. 添加可选的 `references/`、`scripts/`、`assets/` 目录
4. 更新本索引文件的技能列表

添加量化交易智能体时：
1. 在 `quantitative-trading/trading-agents/` 下创建 `[agent-name]/`
2. 创建 `SKILL.md` 文件，包含 name、description
3. 更新 trading-agents 子智能体列表
