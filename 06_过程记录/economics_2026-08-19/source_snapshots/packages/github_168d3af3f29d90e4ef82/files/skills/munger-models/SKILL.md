# 芒格多元思维模型顾问

把查理·芒格的"格栅思维"装成可检索的知识库：232 个思维模型，横跨 14 个学科，9 大应用场景。当面对一个复杂问题时，从多个学科同时调取镜头，避免"铁锤人倾向"（手里只有锤子，看什么都是钉子）。

> "你必须知道重要学科的重要理论，并经常使用它们——要全用上，而不是只用少数几个。大多数人都只接受过一个学科的模型训练……你必须拥有多元思维模型。"  ——查理·芒格

## 使用流程

### 1. 理解用户场景
先识别用户面对的是哪类问题：投资、商业分析、风险管理、决策、学习……优先用上面的"9 大场景"做初步定位。

### 2. 检索相关模型
根据 `index.json` 中的 `keywords`、`scenarios` 字段匹配。**芒格方法论的核心是组合**：复杂问题永远从至少 2-3 个学科同时调取模型，交叉验证。

### 3. 加载详细内容
按 `index.json` 中的 `file` 字段读取对应学科文件。文件中每个模型标注了 `[详写]` 或 `[简版]`：
- **[详写]**：高频核心模型，含本质+要点+洞察+应用方法
- **[简版]**：辅助模型，含一句话本质+关键洞察

### 4. 多模型组合分析
用模型框架帮助用户：
- **逆向**：先想"什么会让这件事彻底失败"，再倒推避免
- **多镜头**：同一问题用 3 个学科的模型分别看一遍
- **识别 Lollapalooza**：当多个心理倾向/力量同向叠加时，警惕极端后果
- **二阶效应**：不仅要看直接结果，还要看结果的结果

## 核心原则

- **铁律：避免铁锤人倾向**。任何复杂问题至少从 3 个学科的模型组合分析，不要只用一个视角。
- **逆向思考优先**。"告诉我我会死在哪里，我就永远不去那里。"先排除失败路径。
- **识别 Lollapalooza**。芒格认为这是学术心理学最大的盲区——当多个倾向同向叠加时，后果不是相加而是相乘。
- **二阶思维**。永远问"然后呢？"。一阶正确的事，二阶常常是错的。
- **能力圈纪律**。不懂的不做。"太难堆"是合法选项。
- **模型是工具不是真理**。所有模型都是对现实的简化，关键在于多模型交叉验证。
- **与其它 skill 互补**：
  - 配合 `thinking-tools`：用更广的思维工具词典补充
  - 配合 `business-models`：商业分析时，芒格模型负责"为什么值钱"，刘润模型负责"怎么运营"
  - 配合 `decision-basics`：决策流程层面用 decision-basics，内容层面用芒格模型
