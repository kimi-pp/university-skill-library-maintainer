## ⚙️ 自动保鲜与质量机制 / Freshness & Quality Mechanisms

普通知识库"发布即过时"；本 Skill 用一套机制让内容**可溯源、可复核、可保鲜**：

- **调用时实取 / Retrieve-at-invocation**: 法规 / 平台政策 / 供应商格局等快变事实，回答时实时检索核验并标注来源与日期，不靠记忆。
- **三闸串行质控 / Three serial gates**: 每份正式交付物过静态严谨闸门（G1–G13）→ 动态闸门（DG1–DG6）→ 对抗共识门（硬不变量 HI-1~HI-8 + 多源共识 + 置信度 ≥ 0.6），不过进隔离区（非阻塞）。
- **哈希链审计 / Hash-chain audit**: 变更写入不可篡改的演进账本（`CHANGELOG.md` + `scripts/self_iterate.py` SHA-256 链），历史可复核。
- **诚实边界 / Honesty boundary**: 不确定就标「待复核 / TO VERIFY」，绝不以保证"永远正确 / 最新"给出结论。

**对你的意义**: 拿到的参考**有据可查、随时保鲜、不编造**——尤其在法规 / 合规 / 供应商这类强时效内容上。
