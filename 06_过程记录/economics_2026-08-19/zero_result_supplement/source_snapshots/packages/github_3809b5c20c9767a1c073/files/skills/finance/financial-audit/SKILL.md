# Financial Audit

Define objective, scope, criteria, population, sampling approach, evidence, exception treatment, materiality, and limitation. Preserve audit trail and independence.

## Output

Return scope, evidence state, inputs and assumptions, deterministic calculations where applicable, exceptions, source/freshness status, recommended action, and approval gate.
