# Renewal Comparison

Explain what changed and whether the renewal is a win, a watch, or a walk.

## Steps

1. Capture expiring vs proposed: premium, rate, limits, deductibles, forms, endorsements, exposure base.
2. Normalize for exposure change (same-stores rate vs premium swing).
3. Attribute change: exposure, experience, marketplace, coverage grant/restriction, competing quote pressure.
4. Flag silent coverage creep (broader grants) or silent erosion (new exclusions).
5. Recommend: renew as offered / renew with pushback / remarket / non-renew.
