# FonePay Research Skill

## Overview

This skill provides a structured approach to researching FonePay, Nepal's leading digital payment platform operated by Fonepay Payment Service Limited (part of F1Soft Group). It covers APIs, products, technology stack, use cases, compliance requirements, and integration details.

## When to Use

Use this skill when you need to:
- Research FonePay's API offerings and integration methods
- Understand FonePay's product suite (QR, Direct, Bills, Credit Card, FoneTAG, Business solutions)
- Research FonePay's technology stack and architecture
- Understand compliance requirements (PCI DSS, ISO 27001, NRB regulations)
- Explore use cases for merchants, businesses, and consumers
- Find integration documentation and technical specifications
- Research competitors and market position in Nepal's digital payments landscape

## Research Process

### Phase 1: Initial Discovery
1. **Visit official website**: Start with https://fonepay.com/
2. **Identify product offerings**: Note all mentioned products and services
3. **Look for developer/resources sections**: Check for API documentation, developer portals
4. **Check certifications and compliance**: Look for PCI DSS, ISO 27001, NRB licensing info
5. **Examine partner ecosystem**: Review listed partners and integrations

### Phase 2: Technical Deep Dive
1. **API Documentation Search**:
   - Check common paths: /api/, /developers/, /docs/, /documentation/
   - Look for API references, SDKs, webhook documentation
   - Search for sandbox/test environments
   - Find authentication methods (API keys, OAuth, etc.)
2. **Technology Stack Research**:
   - Look for mentions of specific technologies (REST, JSON, webhooks, etc.)
   - Check for mobile SDK information (Android, iOS)
   - Research integration methods (REST API, SDKs, plugins)
3. **Product Deep Dive**:
   - Fonepay QR: QR code payment specifications
   - Fonepay Direct: Direct payment gateway details
   - Fonepay Bills: Bill payment integration
   - Fonepay Credit Card: Card payment processing
   - FoneTAG: NFC/RFID based payments
   - Fonepay Business: Merchant solutions

### Phase 3: Compliance and Security
1. **Regulatory Compliance**:
   - Nepal Rastra Bank (NRB) Payment System Operator license
   - PCI DSS compliance details
   - ISO 27001 information security management
   - Data protection and privacy compliance
2. **Security Features**:
   - Tokenization methods

### Phase 4: Use Cases and Implementation
1. **Merchant Use Cases**:
   - Retail POS integration

2. **Developer Implementation**:
   - API endpoints and request/response formats

3. **Integration Patterns**:
   - Plugin integrations (WooCommerce, Shopify, etc.)

### Phase 5: Validation and Documentation
1. **Verify Information**:
   - Cross-reference information from multiple sources
   - Check for latest API versions and updates
   - Validate compliance certificate validity
2. **Document Findings**:
   - Create structured documentation of findings

- **Assuming API details without verification**: Always confirm API details from official documentation

- **Overlooking regional specifics**: Remember FonePay is Nepal-specific with NRB regulations
- **Confusing similar products**: Distinguish between QR, Direct, Bills, Credit Card, etc.
- **Missing security details**: Pay attention to encryption, tokenization, and compliance details
- **Outdated information**: Verify the currency of information (check last updated dates)
