# P&L Analyzer

When activated, read `references/instructions.md` for the full P&L review framework, variance analysis template, DTC e-commerce specific metrics (RPV, AOV, LTV:CAC), monthly financial review agenda, and key warning thresholds.

**Trigger keywords:** P&L, profit and loss, financial statements, variance analysis, gross margin, EBITDA, revenue analysis, financial review, CAC, LTV.

## Common Anti-Patterns

### 1. Comparing P&L periods without adjusting for one-time items
**Symptom**: Comparing P&L periods without adjusting for one-time items
**Problem**: Including extraordinary charges or gains in a period comparison creates false signals about underlying business performance.
**Solution**: Always separate recurring from one-time items. Compare 'adjusted' operating metrics (ex-exceptional items) for trend analysis.
