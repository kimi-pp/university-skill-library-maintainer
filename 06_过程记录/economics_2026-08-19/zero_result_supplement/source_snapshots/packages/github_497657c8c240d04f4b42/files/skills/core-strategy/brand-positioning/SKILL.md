# Brand Positioning Strategist

## Overview

This skill transforms market context, competitive intelligence, and audience insight into a razor-sharp brand position that informs every downstream marketing decision. Positioning is the strategic foundation — it defines where the brand lives in the customer's mind relative to alternatives. Without clear positioning, brand voice, messaging, creative, and campaigns drift into generic noise.

**Keywords**: brand positioning, value proposition, positioning statement, brand strategy, competitive differentiation, messaging hierarchy, brand architecture, category design, brand platform, brand key, brand essence

## Positioning Process

### Step 1: Strategic Context Audit

Before positioning, build a complete strategic picture:

#### The 4C Analysis
| Dimension | Key Questions | Data Sources |
|-----------|--------------|-------------|
| **Company** | What are our strengths, capabilities, and constraints? What is our origin story? | Internal interviews, financials, product specs |
| **Category** | What category does the customer place us in? What are the category conventions and entry points? | Market reports, search behavior, customer language |
| **Consumer** | What jobs-to-be-done exist? What mental models do they use? What triggers purchase? | Persona research (reference `audience-persona` skill), interviews, reviews |
| **Culture** | What cultural currents, trends, or tensions can we tap into? What cultural moments matter? | Social listening, trend reports, media analysis |

#### Category Entry Points (CEPs)
Map how and when customers think about the category:

```
WHEN do they think about it?
├── Seasonal triggers (e.g., "New Year = gym membership")
├── Life events (e.g., "New baby = insurance review")
├── Problem moments (e.g., "Website crashed = hosting switch")
└── Aspiration moments (e.g., "Saw competitor's success = marketing agency")

WHERE do they start looking?
├── Google search (what queries?)
├── Social media (which platform?)
├── Peer referrals (who do they ask?)
├── Professional networks (which communities?)
└── AI assistants / AI search (what questions?)
```

### Step 2: Positioning Statement

Use the Geoffrey Moore positioning template as the starting point, then refine:

#### The Classic Template
```
For [TARGET AUDIENCE]
who [NEED/PAIN POINT],
[BRAND NAME] is a [CATEGORY/FRAME OF REFERENCE]
that [PRIMARY BENEFIT/PROMISE].
Unlike [PRIMARY COMPETITOR/ALTERNATIVE],
we [KEY DIFFERENTIATOR / REASON TO BELIEVE].
```

#### Working Example
```
For growth-stage B2B SaaS companies
who struggle to convert trial users into paying customers,
Acme Analytics is a product-led growth platform
that reveals exactly where users drop off and why.
Unlike generic analytics tools,
we combine behavioral data with AI-driven intervention recommendations
that increase trial-to-paid conversion by an average of 34%.
```

#### Quality Checks for Positioning Statements
| Check | Question | Pass/Fail |
|-------|---------|-----------|
| **Specific** | Would a competitor make the same claim? If yes → too generic | |
| **Truthful** | Can you prove it with data, case studies, or product features? | |
| **Relevant** | Does the target audience actually care about this benefit? | |
| **Differentiated** | Does it create clear distance from the competitive set? | |
| **Simple** | Can a new employee explain it in 30 seconds? | |
| **Durable** | Will this still be true in 2-3 years? | |

### Step 3: Brand Architecture

Define how brands/products/services relate to each other:

#### Architecture Models

| Model | Structure | Best For | Risk |
|-------|----------|---------|------|
| **Branded House** | One master brand, descriptive sub-brands (e.g., FedEx Express, FedEx Ground) | Leveraging single brand equity, B2B | One brand failure affects all |
| **House of Brands** | Independent brands under parent (e.g., P&G → Tide, Pampers, Gillette) | Targeting diverse segments, M&A | Expensive to build each brand |
| **Endorsed** | Sub-brands endorsed by parent (e.g., Courtyard by Marriott) | Best of both worlds | Complex to manage |
| **Hybrid** | Mix of above strategies | Multi-market companies | Requires clear governance |

#### Architecture Decision Matrix
```
Answer these questions to select the right model:

1. Do all products share the same audience?
   YES → Branded House
   NO → House of Brands or Endorsed

2. Does the parent brand have strong equity?
   YES → Endorsed or Branded House
   NO → House of Brands

3. Is the new product in a different category?
   YES → House of Brands
   NO → Branded House

4. Could one product's failure harm others?
   HIGH RISK → House of Brands
   LOW RISK → Branded House
```

### Step 5: Messaging Hierarchy

Build a pyramid of messages from strategic to tactical:

```
                    ┌──────────────┐
                    │ BRAND ESSENCE│ ← 1-3 words (internal compass)
                    │  "Fearless   │
                    │  Innovation" │
                    └──────┬───────┘
                           │
                ┌──────────┴──────────┐
                │   BRAND PROMISE     │ ← 1 sentence (customer-facing)
                │  "We make complex   │
                │  decisions simple"  │
                └──────────┬──────────┘
                           │
          ┌────────────────┼────────────────┐
          │                │                │
    ┌─────┴─────┐  ┌──────┴──────┐  ┌─────┴──────┐
    │ PILLAR 1  │  │  PILLAR 2   │  │  PILLAR 3  │
    │ Clarity   │  │  Speed      │  │  Trust     │
    │           │  │             │  │            │
    │ Proof:    │  │ Proof:      │  │ Proof:     │
    │ - Data    │  │ - Benchmark │  │ - NPS      │
    │ - Case    │  │ - Demo      │  │ - Clients  │
    └───────────┘  └─────────────┘  └────────────┘
          │                │                │
    ┌─────┴──────────────┴──────────────┴──────┐
    │        SUPPORTING MESSAGES               │
    │  Campaigns, ads, emails, social posts    │
    │  all ladder up to a pillar               │
    └──────────────────────────────────────────┘
```

#### Pillar Construction Template

For each messaging pillar:

| Element | Content |
|---------|---------|
| **Pillar Name** | [2-3 word theme] |
| **Pillar Statement** | [1 sentence articulating this theme] |
| **Why It Matters** | [Why the audience cares about this] |
| **Proof Points** | [3-5 evidence items: stats, case studies, features] |
| **Emotional Benefit** | [How this makes them FEEL] |
| **Functional Benefit** | [What this helps them DO] |
| **Example Headlines** | [3 headline options using this pillar] |

### Step 6: Competitive Differentiation Map

Move beyond features to strategic differentiation:

#### Differentiation Levels (from least to most defensible)

| Level | Type | Example | Defensibility |
|-------|------|---------|--------------|
| 1 | **Feature** | "We have X feature" | ⭐ Low — easily copied |
| 2 | **Benefit** | "Get X result" | ⭐⭐ Medium — others claim it too |
| 3 | **Experience** | "We deliver X in a way nobody else does" | ⭐⭐⭐ Good — harder to replicate |
| 4 | **Values** | "We believe X about the world" | ⭐⭐⭐⭐ Strong — core identity |
| 5 | **Category** | "We created the X category" | ⭐⭐⭐⭐⭐ Maximum — you define the rules |

**Goal**: Move UP the differentiation ladder. Most brands are stuck at Level 1-2. Premium brands operate at Level 4-5.

### Step 7: AI-Era Positioning Check

In 2026, brand positioning must also work for:

| Channel | Requirements |
|---------|-------------|
| **AI Search (SGE/AIO)** | Concise, factual statements that AI can parse and cite. Avoid subjective fluff. |
| **Voice Search** | Conversational positioning that answers natural-language questions |
| **LLM Context** | Structured data (schema, FAQ) that makes your brand's position retrievable |
| **Zero-Click SERPs** | Positioning visible in meta descriptions and featured snippets |

**Test**: Ask ChatGPT/Claude/Gemini "What does [Brand] do?" — If the answer is wrong or generic, your positioning isn't reaching AI systems. Fix this with structured website content, consistent messaging, and schema markup.

## Guidelines
- Positioning is a CHOICE. You cannot be everything to everyone. The hardest part is deciding what you are NOT.
- Test your positioning with real customers, not just internal stakeholders. Internal consensus ≠ market truth.
- Positioning should feel slightly uncomfortable — if everyone agrees easily, it's probably too generic.
- Update positioning annually or when competitive landscape shifts dramatically.
- Always validate against `competitor-analysis` — your position must create distance from competitors.
- The best positioning feels OBVIOUS in hindsight but requires courage to commit to.
- Cross-reference with `brand-voice` to ensure HOW you communicate aligns with WHAT you've decided to stand for.
