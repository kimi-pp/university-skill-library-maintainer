## 平台检索结论

- Codeberg：通过公开 API 和站点限定检索未发现可回溯、与 0809 直接相关且满足本轮入口/许可证/包结构要求的独立上游；不为凑平台数量降低门槛。
- SourceHut：公开检索未发现满足相同条件的候选。
- Gitee：发现集合、教程和搬运索引较多；仅保留具有完整 CC0 包结构的 5 个示例，其他索引只作为发现线索，不作为 canonical source。
- Hugging Face：模型和数据集页面可承载 `SKILL.md`，但多数是发现数据集、镜像或需要外部服务的运行包；只把官方、可静态拆分的 3 项能力纳入正式清单，并标明其 canonical source 在官方 GitHub 上游。

## 饱和判断

八个能力群均已有正式候选；14 个专业均能通过主能力群映射到候选。GitHub 搜索出现明显的 registry 搬运和同名复制，继续扩展主要增加重复项而非新能力。跨平台检索在 GitLab、Gitee、Hugging Face 获得了独立上游；Codeberg 和 SourceHut 本轮无安全合格增量，因此停止发现并转入报告阶段。
