# Chapter 8: Constant Capital and Variable Capital

## Core Idea
Different elements of the labour-process contribute differently to product value. Labour adds new value through abstract labour, while means of production preserve their value through concrete labour's specific forms. This dual character of labour explains the distinction between constant and variable capital.

## Frameworks Introduced

### Labour's Dual Character in Value Formation
- **Abstract Labour**: Creates new value (value-creating labour)
  - How: As general human labour, expenditure of labour-power
  - Measurement: By time (hours, days)
  - Result: Adds new value proportionate to labour time
- **Concrete Labour**: Preserves/transfers value (value-transferring labour)
  - How: As specific useful labour (spinning, weaving, forging)
  - Function: Transfers means of production values to product
  - Mechanism: "By mere contact" transforms dead labour into living factors

### Value Transfer Mechanism
- **Process**: Means of production values are preserved by being transferred to the product
- **Agent**: Concrete labour in its specific form (spinning transfers cotton/spindle value to yarn)
- **Timing**: Transfer occurs during labour-process, through labour's contact with materials
- **Condition**: Without the specific useful character, value transfer cannot happen

### Why Transfer is Not Automatic
- **Single operation**: Labour simultaneously adds new value AND preserves old value
- **Two-fold result**: Requires explanation through labour's dual character
- **Example**: Spinner's abstract labour adds value; spinner's concrete labour (spinning) transfers cotton value to yarn
- **Test**: If labour form changes (spinner becomes joiner), value transfer stops for spinning-specific materials

## Key Concepts
- **Constant Capital**: Value transferred from means of production; magnitude unchanged
- **Variable Capital**: Labour-power that creates new value; magnitude changes (v → v+s)
- **Abstract Labour**: Labour as general human effort; source of new value
- **Concrete Labour**: Labour in specific useful form; vehicle of value transfer
- **Value Preservation**: Transfer of existing value from inputs to outputs
- **Value Creation**: Addition of new value through labour
- **Simultaneous Process**: Labour's two-fold nature produces both results at once

## Key Takeaways
1. Labour's dual character explains value formation: abstract labour creates value, concrete labour transfers it
2. Value transfer requires specific useful labour: spinner can't transfer cotton value as a joiner
3. Constant capital preserves its value through labour; variable capital expands its value through labour
4. The two-fold result (value creation + value transfer) occurs in a single labour operation
