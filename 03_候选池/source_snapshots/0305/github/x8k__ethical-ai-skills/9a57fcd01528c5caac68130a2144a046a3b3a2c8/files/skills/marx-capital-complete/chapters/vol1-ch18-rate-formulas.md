# Chapter 18: Various Formulas for the Rate of Surplus-Value

## Core Idea
While the rate of surplus-value is correctly expressed as s/v or surplus-labour/necessary-labour, classical political economy uses derivative formulas that falsely represent the actual degree of exploitation. This chapter identifies and critiques these misleading formulas.

## Frameworks Introduced

### Correct Formulas (Set I)
- **Formula 1**: s / v (surplus-value / variable capital)
- **Formula 2**: Surplus-value / Value of labour-power
- **Formula 3**: Surplus-labour / Necessary labour
- **Characteristics**: Rigorously definite and correct; represent ratio of values or times
- **Relationship**: Formulas 1 and 2 are value ratios; Formula 3 is time ratio; all equivalent

### Incorrect Derivative Formulas (Set II)
- **Formula 4**: Surplus-labour / Working day
- **Formula 5**: Surplus-value / Value of the Product
- **Formula 6**: Surplus-product / Total Product
- **Problem**: These formulas express the ratio as part of the total rather than relative to necessary labour
- **Effect**: Understate the true degree of exploitation

### The Error Demonstration
- **Correct representation**: 6h surplus / 6h necessary = 100% exploitation
- **Incorrect representation (Formula 4)**: 6h surplus / 12h total = 50%
- **Incorrect representation (Formula 5)**: 3s surplus-value / 6s total value = 50%
- **Result**: True rate of exploitation (100%) appears as only 50%

### Why the Error Matters
- **False appearance**: Capitalist exploitation appears less severe than it is
- **Ideological function**: Obscures the true relationship between capital and labour
- **Classical economy's mistake**: Unconsciously used these formulas without understanding the distortion
- **Practical effect**: Workers and economists misjudge the actual degree of exploitation

### Correct Application
- **Always use**: s/v or surplus-labour/necessary-labour for true exploitation rate
- **Avoid**: Ratios that use total working day, total product value, or total product
- **Remember**: The rate measures exploitation relative to necessary labour, not relative to total input

## Key Concepts
- **Rate of Surplus-Value**: True measure of exploitation = s/v
- **Surplus-Labour**: Labour time beyond necessary labour
- **Necessary Labour**: Labour time that reproduces labour-power value
- **Surplus-Product**: Product created during surplus-labour time
- **Total Product**: Entire product of the working day
- **Value of the Product**: Total new value created (v + s)

## Key Takeaways
1. The rate of surplus-value must be expressed relative to necessary labour, not total inputs
2. Classical political economy unconsciously used misleading derivative formulas
3. Formulas using total working day or total product understate exploitation by half
4. Correct formulas: s/v or surplus-labour/necessary-labour
5. Incorrect formulas: surplus-labour/working-day or surplus-value/value-of-product
