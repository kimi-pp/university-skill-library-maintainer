# 两方案核心规则对照表（快速参考）

本表用于快速判断某条引注归属哪种方案，以及在两方案间转换时的关键差异点。

## 一、整体体例差异

| 维度 | GB/T 7714—2015（方案 A） | 《法学引注手册》（方案 B） |
|------|-------------------------|---------------------------|
| **主要适用场景** | 通用学术论文、多数高校学报、理工科期刊、部分法学期刊（清华法学等）、学位论文 | 《中国法学》《法学研究》《中外法学》等几乎全部主流法学期刊；法律出版社等法律图书 |
| **注释位置** | 文后参考文献表（+ 正文内标注） | 页下脚注 |
| **两种模式** | 顺序编码制 / 著者-出版年制 | 只用脚注，连续编号 |
| **标点符号系统** | 英文半角 `. : , ; //` | 中文全角 `：，、；。` |
| **书刊名标示** | 无（靠位置和 `[M]/[J]` 识别） | **《》**（书名号） |
| **文献类型标识** | `[M][J][N][R][D][S][P][A][EB/OL]…` 必备 | 不使用 |
| **析出文献引领** | 期刊用 `.`，图书用 `//` | 全部用 "载" |
| **多作者缩写** | 3 人以上写 3 人 + "等"/"et al." | 3 人以内全列；4 人以上可写 1—2 位 + "等" |

## 二、作者写法

| 作者类型 | 方案 A | 方案 B |
|----------|--------|--------|
| 中文作者 | `张新宝` 或拼音 `ZHANG Xinbao` / `ZHANG X B` | `张新宝` |
| 中文合作 | `李四光, 华罗庚, 茅以升` | `李四光、华罗庚、茅以升` |
| 原创 | 作者后 `.` 直接接题名 | 作者后**冒号**接《》题名，**不写"著"** |
| 主编 | 不特别区分 | `张三主编：` |
| 译者 | 书名后，如 `谢远涛, 译.` | 书名后，如 `郑戈译，` |
| 外籍作者 | 原文姓全大写：`SMITH J` 或中译名只写姓："昂温" | 姓名前加 `[国籍]`：`[美]富勒` |
| 古籍作者 | 原文作者信息 | 姓名前加 `（朝代）`：`（清）沈家本` |

## 三、图书引用对比

**同一条图书**：张新宝《侵权责任法》第5版，人大社2020年，第73—75页。

```
方案 A：
张新宝. 侵权责任法[M]. 5版. 北京: 中国人民大学出版社, 2020: 73-75.

方案 B：
张新宝：《侵权责任法》（第5版），中国人民大学出版社2020年版，第73-75页。
```

**同一条译著**：富勒《法律的道德性》，郑戈译，商务印书馆2005年。

```
方案 A：
富勒. 法律的道德性[M]. 郑戈, 译. 北京: 商务印书馆, 2005.

方案 B：
[美]富勒：《法律的道德性》，郑戈译，商务印书馆2005年版。
```

## 七、法律文件引用对比

GB/T 7714 没有专门的法律文件格式，只能"凑"用标准 `[S]` 或电子资源 `[A/OL]`。

```
方案 A（凑用）：
《民法典》第1224条。                      # 正文内直接引用条文
全国人民代表大会. 中华人民共和国民法典[A/OL]. 2020-05-28. http://...  # 完整引用文本时

方案 B（专门规则）：
《民法典》第1224条第1款第2项。
《国务院关于在全国建立农村最低生活保障制度的通知》（国发〔2007〕19号），第四节。
```

## 十一、方案选择建议

**建议用方案 A（GB/T 7714—2015）的场景**：

- 硕士、博士学位论文（多数高校按国标要求）
- 投稿高校综合性学报（哲社版）
- 写作非纯法学的跨学科论文
- 期刊明确要求"GB/T 7714"或"参考文献著录规则"

**建议用方案 B（《法学引注手册》）的场景**：

- 投稿主流法学期刊（《中国法学》《法学研究》《中外法学》《法学》《中国法律评论》《清华法学》《政法论坛》《法学家》《比较法研究》等）
- 在法律出版社、北京大学出版社（法律类）、中国人民大学出版社（法律类）出版图书
- 大多数法学学科的会议论文集

**当用户犹豫时的推荐**：法学领域**优先用方案 B**，因为它是法学界的事实标准。
