# 《法学引注手册》校对清单（方案 B）

依据：**《法学引注手册》**（第二版，法学引注手册编写组编，中国法学会法学期刊研究会推荐使用）。

本清单按文献类型组织，每类列出"基本格式 / 要素 / 示例 / 常见错误"。

---

## 一、基础规则（§1—§24）

### 1.1 注释位置

- **默认使用页下脚注**。仅在图表说明、文中夹注等特殊情形用其他形式。
- 引注序号：阿拉伯数字，可带圆圈、六角括号或不带。论文建议连续编号。

### 1.2 引领词（§8）

| 引领词 | 何时使用 |
|--------|----------|
| 省略 | 原文引用（带引号）；引用法条、案例 |
| **参见** | 概括引用他人观点 |
| **又见** | 同一文献有不同出处，相互印证 |
| **另见** | 提及其他相关文献 |
| **载** | 文章来源于期刊、报纸、网络、文集（所有析出文献） |
| **转引自** | 无法查到原初文献时引用二手文献 |

### 1.3 标点符号

- 中文文献使用**中文全角**标点 `：，、；。`
- 作者与作品之间：**冒号 `：`**（全角）
- 其他要素之间：**逗号 `，`**（全角）
- 同一要素的多个信息之间：**顿号 `、`**
- 文献名用 `《》`（书名号）
- 文章标题用 `《》`（书名号），**不用引号**
- 英文文献使用英文半角 `, . ;`
- 并列书名号之间**不加顿号**：`《刑法》《民法典》《行政诉讼法》`

### 1.4 再次引用的略写（§13）

第一次必须完整。再次引用时：

- **学术文献**：`同前注〔16〕，耶林书，第3页。` 或 `同前注〔16〕，张文显、于宁文，第69页。`
- **前后紧邻**相同文献：`同上注。` 或 `同上注，第50页。`
- **英文**：`supra note 11, p. 110.` 或 `Ibid., p. 106.`
- 定稿前不建议略写。

### 1.5 文中夹注（§14）

- 常见古籍：`（《尚书·皋陶谟》）`
- 外文术语第一次出现：`毕克尔（Alexander Bickel）`
- 多次引用同一文献的页码：`（第24-28页）`

## 二、中文纸质文献

### 2.1 图书（§25—§49）

**基本格式**：
```
作者：《书名》（版本），出版社出版年版，第×页。
```

**要素与示例**：

| 要素 | 规则 | 示例 |
|------|------|------|
| 作者 | 姓名之后用冒号`：` | `张新宝：` |
| 著作方式 | 原创不写"著"；其他写"主编/编/编译/译注/整理/点校" | `陈兴良主编：` |
| 外籍作者 | 姓名前用方括号`[]`注国籍 | `[美]富勒：` |
| 古籍作者 | 姓名前用圆括号`()`注朝代 | `（清）沈家本：` |
| 合作作者 | 1—3 人全列，顿号间隔；4 人以上写 1—2 人加"等" | `罗豪才、袁曙宏、李文栋：` |
| 书名 | 加《》 | `《美国行政法》` |
| 版次 | 书名后加括号；**初版不写** | `（第5版）` |
| 译者 | 书名后，出版信息前 | `郑戈译，` |
| 校对者 | 译者后 | `宋华琳校，` |
| 出版社 | 完整全称，不写地名 | `中国人民大学出版社` |
| 出版年 | **只写年份**，后加"版" | `2020年版` |
| 页码 | `第×页`或`第×-×页` | `第73-75页` |
| 章节 | 可替代页码 | `第二章"英美判例法"` |

**标准示例**：
```
王名扬：《美国行政法》，中国法制出版社1995年版，第18页。
张新宝：《侵权责任法》（第5版），中国人民大学出版社2020年版，第73-75页。
[美]富勒：《法律的道德性》，郑戈译，商务印书馆2005年版。
（清）沈家本：《历代刑法考》，邓经元、骈宇骞点校，中华书局1985年版。
```

### 2.2 期刊论文（§43）

**基本格式**：
```
作者：《文章标题》，载《期刊名》年份第×期，第×页。
```

**要点**：
- 文章标题用《》
- 期刊名用《》
- 前必须有**"载"**字
- 期刊的"法学版/社会科学版"等括注在《》内
- 集刊用 `第×卷第×辑`，要写出版社和年份

**示例**：
```
季卫东：《法律程序的意义——对中国法制建设的另一种思考》，载《中国社会科学》1993年第1期，第91页。
梁慧星主编：《民商法论丛》第1卷，法律出版社1994年版。
```

### 2.3 报纸文章（§38、§45）

**基本格式**：
```
作者：《文章标题》，载《报纸名》YYYY年M月D日，第×版。
```

**示例**：
```
何海波：《判决书上网》，载《法制日报》2000年5月21日，第2版。
```

- 版面不写"第02版"，写 `第2版`。

### 2.4 文集中的文章（§42）

**基本格式**：
```
作者：《文章标题》，载编者主编：《文集名》，出版社出版年版，第×页。
```

**示例**：
```
王保树：《股份有限公司机关构造中的董事和董事会》，载梁慧星主编：《民商法论丛》第1卷，法律出版社1994年版，第110页。
```

### 2.5 古籍（§34、§46）

- 作者前标朝代 `（朝代）`。
- 常用典籍（《论语》《资治通鉴》二十四史等）可省作者。
- 书名后可标卷次：`《唐会要》，卷三十九《定格令》`。
- 常用古籍无内容争议时，可省出版信息：`《论语·述而》。`

**示例**：
```
（宋）王溥：《唐会要》，卷三十九《定格令》，上海古籍出版社2006年版，第825页。
《论语·述而》。
```

## 三、网络文献（§50—§56）

### 3.1 一般网络文献

**基本格式**：
```
作者：《文章标题》，载网站名 YYYY年M月D日，http://…。
```

**要点**：
- 网站名与上传日期之间**不加逗号**
- 上传日期与网页链接之间**加逗号**
- 网页链接已含日期可不重复标
- 网页无上传日期时标 `YYYY年M月D日访问`
- 不写"最后访问"

**示例**：
```
梁秋坪、郝萍：《全国打击治理农村赌博工作现场会召开》，载人民网2024年10月12日，http://society.people.com.cn/n1/2024/1012/c1008-40337761.html。
法国最高行政法院网站，https://conseil-etat.fr/zh，2024年10月8日访问。
```

### 3.2 微信公众号

```
作者：《文章标题》，载微信公众号"名称"YYYY年M月D日。
```

- 不要求标网页链接。

### 3.3 App

```
作者：《文章标题》，载"App名"App YYYY年M月D日。
```

### 3.4 博客与微博

- 博客：`作者：《标题》，载网站名 日期，链接。`
- 微博：`微博账号 日期，链接。`

## 四、未发表文献（§59—§65）

### 4.1 学位论文（§64）

**基本格式**：
```
作者：《论文题目》，学位授予单位年份学位层级论文，第×页。
```

**示例**：

李松锋：《游走在上帝与凯撒之间——美国宪法第一修正案中的政教关系研究》，中国政法大学2013年博士学位论文，第30页。

### 4.2 会议论文（§63）

```
作者：《论文题目》，会议名称会议论文，YYYY年M月D日于地点。
```

### 4.3 档案（§65）

```
作者：《文献名》（形成时间），保管机构档案名称，档案号。
```

## 五、法律文件（§66—§86）

### 5.1 法律法规规章（§67—§71）

**基本格式**：`《法律名称》第×条第×款第×项`

**要点**：
- 法律文件名用《》
- "中华人民共和国"可省略
- 条、款、项、目用**阿拉伯数字**，序数括号省略
- 法律增订条文的"之一""之二"不改阿拉伯数字
- 初次提到大名可在括号内说明略称：`（以下简称《九民纪要》）`

**示例**：
```
《民法典》第1224条第1款第2项。
《刑法》第17条之一。
《行政诉讼法》（1989年）第54条第2项第3目。
```

### 5.2 规范性文件（§72—§76）

**基本格式**：`制定机关《文件名》（文号），第×节。`

- 文号年份用**六角括号 `〔〕`**（统一为六角括号），不用圆括号、方括号或方头括号。
- 两个以上机关联合发布：制定机关间用顿号。

**示例**：
```
《国务院关于在全国建立农村最低生活保障制度的通知》（国发〔2007〕19号），第四节。
```

### 5.3 其他官方文件（§77—§80）

- 国家标准：`国家质量监督检验检疫总局、中国国家标准化管理委员会《信息与文献参考文献著录规则》，GB/T 7714—2015。`
- 会议决议：`《中共中央关于全面推进依法治国若干重大问题的决定》，2014年10月23日中国共产党第十八届中央委员会第四次全体会议通过。`
- 会议报告：`李克强：《政府工作报告》，2023年3月5日在第十四届全国人民代表大会第一次会议上。`
- 白皮书：标发布机关、白皮书名、发布日期，必要时提供链接。

### 5.4 港澳台法律文件（§81—§83）

- 香港：`《刑事上诉规则》（香港法例第221A章），第42（3）条。`
- 澳门：`《澳门特别行政区廉政公署组织法》（第17/2024号法律修改），第4条第8项。`
- 台湾：**严守一个中国原则**，不使用"国立""中央"等表述；无法变通处理的加引号。
  - `我国台湾地区"民法"规定：…`

### 5.5 外国和国际法律文件（§84—§86）

- 外国法律：`英国《1996年仲裁法》`、`美国《统一买卖法》（1906年）`。
- 国际公约：`《联合国海洋法公约》`、`联合国《儿童权利公约》`。
- 联合国文件：文件名、发布机构、编号、发布时间。

## 六、司法案例（§87—§91）

### 6.1 一般格式

```
案例名称，法院名称（YYYY）案号文书类型。
```

**示例**：
```
苏嘉鸿诉中国证监会行政处罚案，北京市高级人民法院（2018）京行终445号行政判决书。
包郑照等诉苍南县人民政府强制拆除房屋案，浙江省高级人民法院（1988）浙法民上字7号民事判决书。
```

### 6.2 案例名称规则

- 民事/行政：`×××（原告）诉×××（被告）×××（案由）案`
- 刑事：`×××（被告人）×××（指控罪名）案`
- 当事人原则上用真名；隐私保护用化名或隐名 `（化名）`
- 一方有多人用"等"或"等×人"
- 案由从简，一般不写"纠纷"；可省略审级

### 6.3 案例来源

- 指导案例：`最高人民法院指导案例24号（2014年）`
- 公报案例：`载《最高人民法院公报》2015年第11期。`
- 人民法院案例库：`人民法院案例库2024-18-2-053-001。`
- 媒体报道：按报纸文章格式
- 行政复议、仲裁：参照判决书格式，如 `中国证监会〔2017〕63号行政复议决定书。`

## 七、外文文献

### 7.1 英文（§99—§115）

**引领词**：`See / also see / in / supra / Ibid.`

**图书基本格式**：
```
作者名 姓, 书名, 出版社, 年, p. 页码.
```

**示例**：
```
William P. Alford, To Steal a Book Is an Elegant Offense: Intellectual Property Law in Chinese Civilization, Stanford University Press, 1995, p. 98-100.
```

**期刊文章基本格式**（两种之一，同一作品中统一）：
```
# 方式一（期刊卷号在前）：
Charles A. Reich, The New Property, 73 Yale Law Journal 733, 737-738 (1964).

# 方式二（卷号在名称后）：
Stephen J. Choi & A. C. Pritchard, Behavioral Economics and the SEC, Stanford Law Review, Vol. 56:1, p. 1-73 (2003).
```

**关键细则**：

| 要素 | 规则 |
|------|------|
| 作者姓名 | 名在前、姓在后；首字母大写，不用斜体 |
| 文章/书名 | **实词首字母大写，斜体，不加引号** |
| 期刊/报纸名 | 实词首字母大写，**不用斜体** |
| 2 作者 | 用 `&` 连接 |
| 3 作者 | 分别用 `,` 和 `&` 连接 |
| 超过 3 作者 | 可只写 1—2 位 + `et al.` |
| 编者 | 加 `ed.` 或 `chief ed.`（1 人）/ `eds.`（多人） |
| 译者 | 书名后加 `translated by 译者名` |
| 版次 | 书名后括注 `(10th ed.)` |
| 报纸日期 | **"日—月—年"** 格式：`15 June 1990`，不写 `June 15, 1990` |
| 华人作者 | 姓氏用**大写字母或小型大写字母**：`ZHANG Li` 而非 `Zhang Li` |
| 再次引用 | `Alford, supra note 11, p. 110.` 或 `Ibid., p. 106.` |
| 页码 | 前加 `p.`（单复数均用 `p.` 不用 `pp.`）；期刊卷号格式中不用 `p.` |

**英文法律案例**：

```
# 美国：
Chevron U.S.A., Inc. v. Natural Resources Defense Council, Inc., 467 U.S. 837 (1984).

# 英国（官方报告）：
Ridge v. Baldwin [1964] AC 40.

# 英国（neutral citation）：
Lloyd v. Google LLC [2019] EWCA Civ 1599, para. 30.
```

### 7.2 法文（§116—§122）

```
Jacques Chevallier, L'Etat de droit, 4e éd., Montchrestien, 2003, p. 16-29.
```
- 书名斜体；版次用上标 `e`。
- 合作作者用 `et`；超过 3 人用 `et al.`；编者后加 `dir.`。
- 再次引用用 `op. cit.` / `Ibid.`。

### 7.3 德文（§123—§128）

```
Claus Roxin, Strafrecht Allgemeiner Teil, Band I, 4. Aufl., C.H.Beck, 2006, § 15 Rn. 19.
```
- 书名斜体；版次 `Aufl.`；章节 `§`；边码 `Rn.`；页码 `S.`。
- 引领词 `vgl.`（参见）、`siehe auch`（另见）、`zitiert nach`（转引自）。
- 再次引用：`Roxin (Fn. 19), S. 101.` 或 `Ibid.`。

### 7.4 意大利文（§129—§134）

```
Angelo Falzea, L'offerta reale e la liberazione coattiva del debitore, Giuffrè, 1947, p. 34 s.
```
- 书名斜体；`s.` = 单数（及下一页），`ss.` = 复数（及以下几页）。
- 再次引用用 `op. cit.` / `Ibid.`。

### 7.5 俄文（§135—§142）

- 书名斜体，作者首字母大写。
- 期刊用双斜线 `//` 连接。
- 引领词 `См.`（参见）、`См. прим.`（参见前注）。

### 7.6 日文（§143—§150）

```
我妻榮『新訂担保物權法（民法講義Ⅲ）』（有斐閣，1971年）50頁。
```
- 书名用日文引号 `『 』`
- 文章标题用日文引号 `「 」`
- 作者之间用 `=` 连接
- 年份用**公元纪年**，不用日本天皇年号
- 引领词 `参照`
- 再次引用：`佐藤英明・前揭注〔3〕240頁。`

### 7.7 多语种混合（§10）

- 同一脚注中多语种：引领词用第一条文献的语言；分号用该语种符号；结尾句号用最后一条文献语种的符号。

## 八、关键易错点检查（论文常见问题 Top 20）

| 错误模式 | 正确写法 |
|----------|----------|
| `张三著：《民法》` ❌ | `张三：《民法》` ✅（原创作品省"著"） |
| `《民法典》（2020年版）` ❌（指法典版本而非出版版本） | `《民法典》` ✅ |
| `2020年` 不加"版" ❌ | `2020年版` ✅ |
| `第一版`/`初版` ❌ | 第 1 版不写 ✅ |
| `中国人民大学出版社：` ❌（出版社后加冒号） | `中国人民大学出版社2020年版` ✅ |
| `北京：法律出版社` ❌（写了城市） | `法律出版社` ✅ |
| `2020年3月版` ❌（无需月份） | `2020年版` ✅（除非必要） |
| `pp. 10-15` ❌ | `第10-15页` ✅（中文） |
| `见《民法典》第1条` ❌（见字多余） | `《民法典》第1条` ✅ |
| 概括引用不写"参见" ❌ | `参见…` ✅ |
| 期刊文章前不写"载" ❌ | `载《中国法学》2020年第1期` ✅ |
| 《法制日报》2020年3月5日第A2版 ❌ | `《法制日报》2020年3月5日，第2版` ✅ |
| 法条编号用中文"第一百二十四条" ❌（学术文章） | `第124条` ✅（原文引用除外） |
| 文号年份 `(2007)19号` ❌ | `〔2007〕19号` ✅（六角括号） |
| `[美]史密斯·约翰` ❌（国籍简称不当） | `[美]约翰·史密斯` ✅ |
| `康德（德）` ❌ | `[德]康德` ✅ |
| 并列书名号中用顿号 `《A》、《B》` ❌ | `《A》《B》` ✅ |
| 英文文章名加引号 `"The New Property"` ❌ | `*The New Property*`（斜体）✅ |
| 英文报纸日期 `June 15, 1990` ❌ | `15 June 1990` ✅ |
| 网络文献写"最后访问" ❌ | `2024年10月8日访问` ✅ |
| 微信公众号写网址 ❌ | 可不写网址，标公众号名和日期 ✅ |
| 指导案例写裁判文书 ❌ | 只写 `最高人民法院指导案例24号（2014年）` ✅ |
| 案例名称写"…纠纷案" ❌（冗余） | `…相邻关系案` ✅（案由从简） |
| 古籍作者不标朝代 ❌ | `（清）沈家本` ✅ |
