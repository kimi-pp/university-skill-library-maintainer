# GB/T 7714—2015 校对清单（方案 A）

依据：**GB/T 7714—2015《信息与文献 参考文献著录规则》**（2015-05-15 发布，2015-12-01 实施，代替 GB/T 7714—2005）。

## 一、整体结构

### A.1 排列方式（二选一，全文统一）

| 组织方式 | 正文标注 | 表内排序 |
|----------|----------|----------|
| **顺序编码制**（常用） | `[序号]` 置于右上角或括注，如 `…观点[1]` | 按正文首次出现顺序编号 |
| **著者-出版年制** | `(著者 姓, 出版年)` | 按中/日/西/俄/其他文种分组，再按字顺和年 |

- 顺序编码制下，序号用方括号 `[1][2]…`；如用脚注，可用计算机自动生成的圈码 `①②③`。
- 多次引用同一文献：顺序编码制下只编一个号，在 `[]` 外加引文页码，如 `[2]260`；脚注形式可用 `同②326-329`。

### A.2 标识符的使用（§7）

每个参考文献条目使用下列**前置符**：

| 符号 | 用于 |
|------|------|
| `.` | 题名项、析出文献题名项、其他责任者、版本项、出版项、获取路径、DOI 前；每条结尾可用 `.` |
| `:` | 其他题名信息、出版者、引文页码、析出文献页码、专利号前 |
| `,` | 同一责任者的多个"等"/"译"前、出版年前、年卷期中的年和卷前 |
| `;` | 同一责任者的合订题名、同一条目连载的后续年卷期页码前 |
| `//` | 专著中析出文献的出处项前 |
| `( )` | 期刊的期号、报纸版次、电子资源更新日期、非公元纪年 |
| `[ ]` | 文献序号、文献类型标识、引用日期、自拟信息 |
| `/` | 合期期号之间、文献载体标识前 |

**注**：本标准使用**英文半角**标点，不是中文全角。是 `.` 不是 `。`，是 `:` 不是 `：`。

## 二、文献类型标识（§8.2.2 + 附录 B）

所有条目必须在题名后标 `[字母]`，**任选**但强烈建议标出。

| 类型 | 代码 | 类型 | 代码 |
|------|------|------|------|
| 普通图书 | M | 学位论文 | D |
| 会议录 | C | 报告 | R |
| 汇编 | G | 标准 | S |
| 报纸 | N | 专利 | P |
| 期刊 | J | 数据库 | DB |
| 档案 | A | 计算机程序 | CP |
| 舆图 | CM | 电子公告 | EB |
| 数据集 | DS | 其他 | Z |

**电子资源**需双载体标识 `[类型/载体]`：

| 载体 | 代码 |
|------|------|
| 磁带 | MT |
| 磁盘 | DK |
| 光盘 | CD |
| 联机网络 | OL |

常见组合：`[M/OL]`、`[J/OL]`、`[N/OL]`、`[EB/OL]`、`[D/OL]`。

## 三、各类型完整著录格式

### B.1 专著（图书）

```
主要责任者. 题名: 其他题名信息[文献类型标识/文献载体标识]. 其他责任者. 版本项. 出版地: 出版者, 出版年: 引文页码[引用日期]. 获取和访问路径. DOI.
```

**示例**：
```
陈登原. 国史旧闻: 第1卷[M]. 北京: 中华书局, 2000: 29.
哈里森, 沃尔德伦. 经济数学与金融数学[M]. 谢远涛, 译. 北京: 中国人民大学出版社, 2012: 235-236.
库恩. 科学革命的结构: 第4版[M]. 金吾伦, 胡新和, 译. 2版. 北京: 北京大学出版社, 2012.
```

### B.2 专著中的析出文献（图书章节）

```
析出文献主要责任者. 析出文献题名[M]. //专著主要责任者. 专著题名: 其他题名信息. 版本项. 出版地: 出版者, 出版年: 析出文献页码.
```

**示例**：
```
程根伟. 1998年长江洪水的成因与减灾对策[M]//许厚泽, 赵其国. 长江流域洪涝灾害与科技对策. 北京: 科学出版社, 1999: 32-36.
```

### B.3 连续出版物（整本期刊）

```
主要责任者. 题名: 其他题名信息[J]. 年, 卷(期)-年, 卷(期). 出版地: 出版者, 出版年[引用日期].
```

### B.4 连续出版物中的析出文献（期刊论文）⭐ 法学常用

```
析出文献主要责任者. 析出文献题名[J]. 连续出版物题名, 年, 卷(期): 页码.
```

**示例**：
```
关立哲, 韩纪富, 张晨珏. 科技期刊编辑审读中要注重比较思维的科学运用[J]. 编辑学报, 2014, 26(2): 144-146.
余建斌. 我们的科技一直在追赶: 访中国工程院院长周济[N/OL]. 人民日报, 2013-01-12(2)[2013-03-20]. http://paper.people.com.cn/rmrb/html/2013-01/12/nw.D110000renmrb_20130112_5-02.htm.
```

### B.5 报纸文章 ⭐ 法学常用

```
作者. 题名[N]. 报纸名, YYYY-MM-DD(版次).
```

**示例**：
```
丁文详. 数字革命与竞争国际化[N]. 中国青年报, 2000-11-20(15).
```

### B.6 学位论文

```
作者. 题名[D]. 所在地: 学位授予单位, 年份: 页码.
```

### B.7 报告

```
作者. 题名: 报告号[R]. 出版地: 出版者, 年份: 页码.
```

### B.8 标准

```
提出机构. 标准题名: 标准号[S]. 出版地: 出版者, 出版年: 页码.
```

**示例**：
```
全国信息与文献标准化技术委员会. 信息与文献 都柏林核心元数据元素集: GB/T 25100—2010[S]. 北京: 中国标准出版社, 2010: 2-3.
```

### B.9 专利

```
专利申请者. 题名: 专利号[P]. 公告/公开日期.
```

### B.10 电子资源（其他）

```
主要责任者. 题名: 其他题名信息[EB/OL]. 出版地: 出版者, 出版年: 页码(更新或修改日期)[引用日期]. 获取路径. DOI.
```

**示例**：
```
萧钰. 出版业信息化迈入快车道[EB/OL]. (2001-12-19)[2002-04-15]. http://www.creader.com/news/20011219/200112190019.html.
```

## 四、关键细则

### D.1 作者（§8.1）

- 个人著者：**姓在前，名在后**。
- 欧美著者姓名：**姓全大写，名可缩写**，缩写点省略。
  - `Albert Einstein` → `EINSTEIN A`
  - `Augustus De Morgan` → `DE MORGAN A`
  - `Amabel Williams-Ellis` → `WILLIAMS-ELLIS A`
- 中文作者汉语拼音（依 GB/T 28039—2011）：**姓全大写，名可缩写取首字母**。
  - `李江宁` → `LI Jiangning` 或 `LI J N`
- 欧美著者的中译名只写姓；同姓不同名才加首字母（如"昂温 G,昂温 P S"）。
- **超过 3 人**时：著录前 3 人，加"等"或"et al."。
- 不明/佚名：顺序编码制可省略，著者-年制写"Anon"或"佚名"。
- 机关团体：上下级用 `.` 分级。中文机关团体除外。
  - `Stanford University. Department of Civil Engineering`

### D.2 版本（§8.3）

- **第 1 版不著录**。
- 其他版本用阿拉伯数字或缩写：`3版`、`5th ed.`、`Rev. ed.`、`新 1 版`、`明刻本`。
- 版本位置：**在出版地之前**，不是书名后。

### D.3 出版地（§8.4.1）

- 只写城市名。
- 同名异地加省/州/国名：`Cambridge, Eng.` / `Cambridge, Mass.`。
- 多个出版地只写第一个。
- 无出版地：中文写 `[出版地不详]`，外文写 `[S.l.]`。

### D.4 出版者（§8.4.2）

- 可用全称，也可用公认简写（如 `IRRI` = International Rice Research Institute）。
- 多个出版者只写第一个。
- 无出版者：中文 `[出版者不详]`，外文 `[s.n.]`。

### D.5 出版日期（§8.4.3）

- **公元纪年**，阿拉伯数字。其他纪年用 `()` 附注，如 `1947（民国三十六年）`。
- 报纸的出版日期用 `YYYY-MM-DD` 格式。
- 出版年不确定：依次选版权年 `c1988`、印刷年 `1995 印刷`、估计年 `[1936]`。

### D.6 页码（§8.5）

- 阿拉伯数字。
- 起讫页用 `~` 或 `-`（实践中多用半角 `-`）。
- 同一文献多次引用时，页码附于序号外：`[2]260`、`[4]326-329`。
- 序言/扉页：`序 2-3`、`扉页`、`第1版自序`。

### D.7 获取路径与 DOI（§8.6、§8.7）

- 电子资源**必备** `获取路径` 和 `DOI`（如有）。
- DOI 写法：`DOI:10.3969/j.issn.xxxx`。
- 顺序：`…[引用日期]. http://… . DOI:xxxx.`

### D.8 页码与年卷期（§8.8）

- 期刊：`年, 卷(期): 页码` 如 `2014, 26(2): 144-146`。
- 合期：`年, 卷(增刊2): 页码` 或 `年(期/期)`，如 `2001(9/10):36-39`。
- 报纸：`YYYY-MM-DD(版次)`。
- 阅读型参考文献记起讫或起始页，引文参考文献记具体页。

### D.9 中文文献的标点 ⚠️

- GB/T 7714 使用**半角标点** `. : , ; //`。
- **不使用**书名号 `《》`、引号 `""` 来标识题名。题名靠位置和标识 `[M][J]` 识别。
- 这是 GB/T 7714 与《法学引注手册》最显眼的区别。

### D.10 双语著录（§6.1）

- 原语种优先。必要时可双语，先原语种后其他语种。

## 五、法学特定类型的处理（GB/T 7714 的局限）

GB/T 7714 没有专门的"法律文件""司法案例""指导性案例""规范性文件""判决书"模板。实际操作建议：

| 法学文献类型 | 推荐处理 |
|--------------|----------|
| 法律、法规、司法解释 | 按"标准文献 [S]"或"档案 [A]"处理，或按"电子资源 [A/OL]"引官方网站版本 |
| 最高院指导性案例 | 按"电子资源 [EB/OL]"处理，标发布机关、指导案例号、发布年 |
| 裁判文书 | 按"档案 [A]"或"电子资源 [EB/OL]"，注明法院、案号、裁判日期 |
| 人民法院案例库 | 按"数据库 [DB/OL]"或"电子资源 [EB/OL]"，标入库编号 |

以上实际操作可能导致该方案在法学论文中"水土不服"。**如用户投稿对象为主流法学期刊（《中国法学》《法学研究》《中外法学》等），强烈建议改用方案 B（法学引注手册）**。

## 六、常见错误速查（本清单 QA 用）

| 错误模式 | 正确写法 |
|----------|----------|
| `张三. 《民法典释义》[M]…` ❌ | `张三. 民法典释义[M]…` ✅（GB/T 7714 不用书名号） |
| `张三．民法…，2020年。` ❌ | `张三. 民法…, 2020.` ✅（半角标点） |
| `李四，"论法治"…` ❌ | `李四. 论法治[J]…` ✅（不用引号标题名） |
| 缺 `[M]/[J]` 标识 ❌ | 补齐类型标识 ✅ |
| `Smith, John` ❌ | `SMITH J` ✅（姓全大写，名缩写） |
| 出版地写 `北京：` 后空格 ❌ | `北京: `（半角冒号+空格）✅ |
| 网页引用不标 `[引用日期]` ❌ | 电子资源**必须**标引用日期 `[YYYY-MM-DD]` ✅ |
| 第 1 版写"第 1 版" ❌ | 省略；只有第 2 版起才著录 `2版` ✅ |
| 缺页码的图书/论文引用 ⚠️ | 引文参考文献应有具体页码；缺则标注请补 |
| URL 与 DOI 重复 | 如 URL 不含 DOI，可另注 DOI；如 URL 已含，省略 DOI |
