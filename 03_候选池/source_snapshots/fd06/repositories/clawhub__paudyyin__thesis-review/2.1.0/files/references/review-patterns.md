# 论文评审实战经验手册

> 基于13篇硕士学位论文评审的实战总结

## 一、评审节奏

一篇硕士论文的典型评审时间分配：

| 阶段 | 时间 | 做什么 |
|------|------|--------|
| 信息提取 | 5分钟 | 从PDF提取基本信息、页数、参考文献数 |
| 快速浏览 | 10分钟 | 摘要→目录→各章小结→结论，建立整体印象 |
| 深入阅读 | 20-30分钟 | 选1-2章核心内容精读，检查理论/方法细节 |
| 文献对比 | 5-10分钟 | web_search搜索最新进展，对比创新性 |
| 撰写意见 | 15-20分钟 | 按模板生成结构化评审意见 |
| 生成文档 | 5分钟 | 输出Word文档 |

总计：约60-80分钟/篇

## 二、快速识别论文质量

### 高质量论文特征
- 创新点明确且与已有工作边界清晰
- 有理论分析（收敛性证明/复杂度分析）
- 实验充分：多数据集/多场景/对比方法多/有消融实验
- 写作规范：图表精致、公式编号规范、参考文献格式统一
- 有实际系统验证（不只是仿真）

### 低质量论文特征
- 创新点模糊，读完全文不知道"新在哪"
- 纯仿真验证，无实物/实际数据
- 实验只对比1-2个baseline，且是最老的方法
- 英文摘要机翻痕迹明显
- 参考文献以中文为主，缺少近3年国际文献

## 三、常见"雷区"

### 1. 创新边界不清（77%出现率）
**典型表现**：
- "本文提出了XX方法"，但XX方法在3年前已有类似工作
- 创新点描述过于笼统："将A应用于B领域"
- 未明确说明与最相关已有工作的区别

**评审建议写法**：
> 论文提出的XX方法与[引用]中的YY方法在核心思路上存在相似性，建议在1.4节明确界定本文方法与该工作的技术差异，可从[具体维度]角度进行对比分析。

### 2. 理论分析不足（69%出现率）
**典型表现**：
- 提出了新算法但无收敛性分析
- 给出了数学模型但无充分/必要条件讨论
- 参数选择缺乏理论依据

**评审建议写法**：
> 建议在第3章补充算法的收敛性分析或计算复杂度分析，为参数XX的选择提供理论依据或实验依据。

### 3. 实验场景单一（62%出现率）
**典型表现**：
- 仅在仿真环境验证
- 只使用一个公开数据集
- 未与近3年的SOTA方法对比

**评审建议写法**：
> 建议增加至少一组公开数据集的实验验证，并与近3年的代表性方法（如[具体方法]）进行对比，以验证方法的泛化性和先进性。

### 4. 写作规范问题（100%出现率）
**高频具体问题**：
- 英文摘要中冠词缺失/时态混用
- 图表缺少单位或图例
- 参考文献格式不统一（有的有页码有的没有）
- 公式编号与章节不对应

## 四、提问技巧

好的提问应该能检验作者是否真正理解自己的工作，而非泛泛而问。

**好的提问示例**：
1. "在公式(3.7)中，权重系数α的取值范围是如何确定的？如果α超出该范围，算法行为会发生什么变化？"
2. "实验结果显示方法A在数据集B上的提升仅为0.5%，请分析该提升是否具有统计显著性？"
3. "论文第4.3节提到未来可以结合XX技术，请具体说明结合方式和预期效果。"

**不好的提问示例**：
1. "请进一步说明你的创新点。"（太笼统）
2. "实验做得不够充分。"（没有具体问题）
3. "参考文献格式需要修改。"（这是修改建议，不是提问）

## 五、答辩建议的判断标准

| 结论 | 判断标准 |
|------|---------|
| 同意答辩 | 创新点清晰、实验充分、写作规范，无重大问题 |
| 修改后答辩 | 有2-3个需要修改的问题，但不影响核心贡献 |
| 重大修改后重审 | 创新边界不清、实验严重不足、或存在学术规范问题 |
| 不同意答辩 | 工作量明显不足、存在抄袭嫌疑、或核心方法有根本性缺陷 |
