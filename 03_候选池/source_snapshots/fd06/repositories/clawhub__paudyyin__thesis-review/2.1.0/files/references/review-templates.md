# 学位论文评审模板参考

> 不同类型论文的评审侧重点

## 学术硕士论文

**评审重点**：理论贡献、方法创新、学术规范

**额外检查项**：
- 文献综述是否覆盖了该领域的经典工作和最新进展
- 理论推导是否严密，假设是否合理
- 是否有收敛性分析或复杂度分析
- 实验是否验证了理论预期

**典型问题数量**：6-8个问题 + 3个提问

## 专业硕士论文

**评审重点**：工程应用价值、系统实现、实际效果

**额外检查项**：
- 是否有明确的工程应用场景
- 系统实现是否完整（不只是算法）
- 是否有实际平台/产品验证
- 性能指标是否满足工程需求

**典型问题数量**：5-7个问题 + 2-3个提问

## 博士论文

**评审重点**：原创性贡献、理论深度、学术影响力

**额外检查项**：
- 是否提出了原创性的理论/方法/框架
- 理论分析是否达到博士水平（严格证明、完整推导）
- 实验是否充分到足以支撑所有声称的贡献
- 是否有多篇高水平论文支撑

**典型问题数量**：8-12个问题 + 4-5个提问

## 跨学科论文评审

当论文涉及非本人研究方向时：

1. 在开头声明："非本人研究方向，仅从方法论和规范性角度评阅"
2. 聚焦于：
   - 研究方法的科学性
   - 实验设计的合理性
   - 写作规范性
   - 创新性的形式判断（是否有新意，而非判断新意的学术价值）
3. 减少理论深度方面的具体批评
4. 总体评价中注明评审局限性
